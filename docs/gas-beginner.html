このハンズオンで作るもの

このハンズオンでは、Google Apps Script (GAS) と Gmail を利用して、毎日のタスクを Gmail で自動通知する簡単なアプリケーションを作成します。GAS と Gmail の基本的な使い方を体験し、実用的なアプリを開発するための基礎を身につけることを目指します。

📨 完成イメージ（処理の流れ）
  1. Google スプレッドシートに「タスク名」と「実施日」を入力する
  2. 指定した時間に GAS がスプレッドシートを読み込み、今日実施予定のタスクを抽出する
  3. 抽出したタスクを Gmail で通知先に自動送信する

🧩 そもそも GAS と Gmail とは？

Google Apps Script (GAS)

GAS は、Google が提供するサーバーサイド JavaScript の実行環境です。Google スプレッドシート、ドキュメント、フォームなどの Google Workspace アプリを操作したり、外部サービスと連携したりするスクリプトを作成できます。サーバーの準備が一切不要で、業務の自動化や効率化を手軽に実現できるのが大きな魅力です。

Gmail（メール送信機能）

GAS にはメールを送信するための標準サービス MailApp が用意されています。本ハンズオンでは MailApp を使って、タスク通知メールを自動送信します。

✅ 必要な環境

  • Google アカウント（普段お使いのもので OK）

学校や会社のアカウントでは、管理者の設定で Apps Script や Gemini が使えない場合があります。参加前に使えるか確かめてください。

🤖 このハンズオンの進め方

コードを丸暗記しなくて大丈夫です。分からないところは Gemini に聞きながら進めましょう。実装は次のサイクルを回すだけで進みます。

  1. 各 Step の「🤖 Gemini にこう聞く」カードにあるプロンプトをコピーして、Gemini に貼ります。
  2. 返ってきたコードを Apps Script エディタへ貼って動かします。
  3. うまく動かないときは、エラー文をそのままコピーして Gemini に「このエラーの原因と直し方を教えて」と聞きます。
  4. どうしても進めないときは、各 Step の折りたたみを開けば答えのコードを確認できます。

Step 1: Google Apps Script を動かしてみよう

📊 スプレッドシートと GAS のつながり

まずは「GAS なるもの」を実際に動かして、スプレッドシートに文字が自動で入る感覚をつかみましょう。難しいことは考えず、まずは Gemini にコードを書いてもらって動かすのがコツです。

1-1. スプレッドシートを作成する

https://docs.google.com/spreadsheets/u/0/ にアクセスし、Google スプレッドシートで新しいシートを作成します。ここでは分かりやすいように、シートの名前を「GASハンズオン」などにしておきましょう。

1-2. スプレッドシート ID とシート名を控える

GAS からスプレッドシートを操作するために、スプレッドシート ID と シート名の 2 つを控えます。スプレッドシート ID は、アドレスバーの URL の中にあります。

📋 控える 2 つの情報

  • スプレッドシート ID → URL の /spreadsheets/d/ と /edit の間の文字列
    例: https://docs.google.com/spreadsheets/d/1BMln2RezVl9lbp4dh0PUnB1f.../edit#gid=0
  • シート名 → 画面下のタブ名（シート1 または Sheet1）

1-3. Apps Script エディタを開く

スプレッドシートのメニューバーから 拡張機能 > Apps Script を開きます。

新しいタブで Apps Script のエディタ画面が開きます。最初は myFunction という空の関数が用意されています。

1-4. まずは Gemini にコードを書いてもらう

「セル A1 に Hello World! と書き込む」だけのシンプルなコードを作ります。下のプロンプトをコピーして Gemini に貼り、返ってきたコードをエディタの内容をすべて消してから貼り付けてください。

💡 このページのプロンプトは短くしてあります。コードの意味を知りたいときは、「日本語のコメントを付けて」と一言足すと各行の説明が入ります。このあとの答え合わせ用コードにも、同じようにコメントを入れてあります。
🤖 Gemini にこう聞く
Google Apps Script で、スプレッドシートを ID で開き、指定した名前のシートの A1 に「Hello World!」と書き込む myFunction を作ってください。スプレッドシートの ID とシート名は、あとで差し替えられるよう先頭で定数にしてください。
⚠️ 1-2 で控えた スプレッドシート ID とシート名への置き換えを忘れずに！ YOUR_SPREADSHEET_ID と YOUR_SHEET_NAME の部分を、ご自身の値に書き換えてください。

コードを保存（💾 アイコン）したうえで、画面上部の 「▶️ 実行」を押してコードを実行します。初回実行時は権限の承認が必要になります。

① 「承認が必要です」と表示されるので 「権限を確認」をクリックします。

② アカウント選択が出たら、自分のアカウントを選びます。次に表示された画面に合わせて進みます。

  • 英語の小さなダイアログで、アプリ名の横に (Unverified) と出た場合：「REVIEW PERMISSIONS」を押すと、次の日本語の画面へ進みます。
  • 「このアプリは Google で確認されていません」と出た場合：「詳細」をクリックし、「（プロジェクト名）（安全ではないページ）に移動」を選択します。
ℹ️ 人から配布されたプログラムでこの画面が出たら注意が必要です。今回は自分で書いたプログラムなので、許可して進めます。権限ごとのチェック欄がある場合は、すべてにチェックを入れてから「許可」を押します。チェックしないと実行時にエラーになります。

③ 最後にアクセスの許可画面が出ます。下までスクロールして「許可」を押すと承認完了です。

画像にはメール送信の権限も表示されていますが、Step 1 のコードで必要なのはスプレッドシートへのアクセス権限だけです。

1-6. 結果を確認する

実行が成功すると、スプレッドシートの A1 セルに「Hello World!」が自動的に挿入されているはずです 🎉

Step 3: タスク通知スクリプトの作成

🔎 シート全体から今日のタスクだけを取り出す

いよいよ本題です。スプレッドシートから今日のタスクを読み取り、メールで通知する処理を、順番に組み立てていきます。今回は myFunction を書き換えていきます。

3-1. 今日のタスクを読み込んで抽出する

まずは A1 に文字を書き込む処理をやめて、スプレッドシートの全データを読み込み、実施日が今日のタスクだけを抜き出すところまで一気に書き換えます。ここから先はいまエディタにあるコードを全文コピーして Gemini に貼り、そのあとにプロンプトを続ける形で進めます。

やることは 3 つです。

  • シートの全データを二次元配列で読み込む
  • 今日の日付を「yyyy/MM/dd」形式の文字列で取り出す（日付どうしを比べるため文字列に揃えます）
  • 1 行目のヘッダーを shift() で取り除き、filter() で今日のタスクだけに絞り込む
🤖 Gemini にこう聞く
（いまのコードを全文貼り付けてから）↑これを書き換えて、A1 への書き込みをやめ、シートの全データを data に読み込んでください。今日の日付を Utilities.formatDate で JST の「yyyy/MM/dd」文字列にし、1行目のヘッダーを除いて、実施日（2列目）が今日の行だけを tasksToday に入れてください。実施日が空欄、または日付として認識されていない行は除いてください。
💡 うまくいかないとき / 答え合わせ用のコードを見る

function myFunction() {
  const spreadsheetId = 'YOUR_SPREADSHEET_ID';
  const sheetName = 'YOUR_SHEET_NAME';
  const ss = SpreadsheetApp.openById(spreadsheetId);
  const sheet = ss.getSheetByName(sheetName);

  // データを取得（シートの全行を二次元配列で受け取る）
  const data = sheet.getDataRange().getValues();

  // 今日の日付を取得（JST・yyyy/MM/dd 形式の文字列にする）
  const today = new Date();
  const formattedToday = Utilities.formatDate(today, 'JST', 'yyyy/MM/dd');

  // ヘッダー行（1行目の見出し）をスキップ
  data.shift();

  // 今日実施予定のタスクを抽出（2列目 row[1] が実施日）
  const tasksToday = data.filter(row =>
    row[1] instanceof Date && Utilities.formatDate(row[1], 'JST', 'yyyy/MM/dd') === formattedToday
  );
}
ℹ️ row[0] が「タスク名」（A 列）、row[1] が「実施日」（B 列）です。配列の番号は 0 から始まることに注意しましょう。

（いまのコードを全文貼り付けてから）↑これに、tasksToday を1件ずつメールで送る処理を足してください。件名と本文はどちらも「本日のタスク: （タスク名）」。宛先は、あとで自分のアドレスに差し替えられるようにしてください。
⚠️ recipientEmail をご自身のメールアドレスに置き換えるのを忘れずに！
💡 うまくいかないとき / 答え合わせ用のコードを見る
After（Gmail 送信処理を追加・これで完成） 
function myFunction() {
  const spreadsheetId = 'YOUR_SPREADSHEET_ID';
  const sheetName = 'YOUR_SHEET_NAME';
  const ss = SpreadsheetApp.openById(spreadsheetId);
  const sheet = ss.getSheetByName(sheetName);

  const data = sheet.getDataRange().getValues();
  const today = new Date();
  const formattedToday = Utilities.formatDate(today, 'JST', 'yyyy/MM/dd');

  data.shift();
  const tasksToday = data.filter(row =>
    row[1] instanceof Date && Utilities.formatDate(row[1], 'JST', 'yyyy/MM/dd') === formattedToday
  );

  // ここから追加
  // Gmail 通知を送信（今日のタスクごとに1通ずつ送る）
  tasksToday.forEach(task => {
    const taskName = task[0];
    const recipientEmail = 'your.email@example.com'; // 自分のメールアドレスに置き換える

    const subject = `本日のタスク: ${taskName}`;
    const body = `本日のタスク: ${taskName}`;

    MailApp.sendEmail({
      to: recipientEmail,
      subject: subject,
      htmlBody: body
    });
  });
  // ここまで追加
}

  • A 列: タスク名 … 実施するタスクの名前（例: テストタスクA）
  • B 列: 実施日 … タスクを実施する日付（yyyy/MM/dd 形式。例: 2026/10/14 ※スプレッドシート側で勝手に日付形式に変換される分には問題ありません）

💡 動作確認のため、実施日には「今日の日付」を入れておきましょう。そうすれば実行時にすぐメールが届きます。

Step 4: GAS トリガーで自動化する

⏰ 「実行」を押す人が、自分からトリガーに変わる

最後に、作った myFunction() を毎日決まった時間に自動実行させましょう。これを実現するのが GAS トリガーです。

4-1. GAS トリガーとは

GAS トリガーとは、スクリプトを自動的に実行するための仕組みです。「特定のイベントが起きたとき」や「指定した時間になったとき」にスクリプトを実行できます。今回は毎日決まった時間に通知を送るため、「時間主導型」トリガーを使います。

4-2. 時間主導型トリガーを設定する

① Apps Script エディタの左側メニューから 「トリガー」（時計のアイコン）を選択します。

② トリガー一覧が開きます。最初は何もないので、右下の 「+ トリガーを追加」をクリックします。

③ トリガーの設定画面で、以下のように設定して 「保存」します。

項目設定値
実行する関数を選択myFunction
実行するデプロイを選択Head（既定のまま）
イベントのソースを選択時間主導型
時間ベースのトリガーのタイプ特定の日時（今日の、今から 3〜5 分後の日時を入力）

画像の日付（2024-10-14）は撮影時のものです。

ℹ️ 「特定の日時」は1回だけ実行するテスト用です。「特定の日時」を 「時間ベースのタイマー」「日付ベースのタイマー」に変えると、毎日◯時に実行のような定期実行も設定できます。実運用ではこちらを使います。毎日のタイマーは「午前7時〜8時」のような1時間の枠で指定し、その中のどこかで動きます（ちょうど7:00とは限りません）。

4-3. 指定時刻に通知が届くことを確認

設定した時刻になると myFunction() が自動実行され、Gmail にタスク通知が届きます。Gmail を確認し、正しく送信されていれば完成です 🎉🎉

毎日自動で動かしたいときは、作ったテスト用トリガーの右端の︙から「トリガーを削除」を選び、もう一度「+ トリガーを追加」から次のように設定して保存します。実行する関数: myFunction／イベントのソース: 時間主導型／時間ベースのトリガーのタイプ: 日付ベースのタイマー／時刻を選択: 午前7時〜8時
