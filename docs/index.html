Claude Cowork 活用ハンズオン 入門

フォルダを渡すだけ Excel・Word を自動作成 プロンプトインジェクション体験 80分進行表つき

散らかったダウンロードフォルダの練習用コピーを Claude Desktop の Cowork に渡し、フォルダ分け・写真や PDF からの期限の拾い出し・売上データ・レシート・スマホ料金からのお金の出入りの集計を任せます。後半は、保存した Web ページに隠れた指示で AI がだまされる場面を試し、渡すフォルダ・承認モード・確かめ方など安全に使う 5 つの約束を確認し、最後に自分の作業を 1 つ選んで頼み方を書きます。各 Step に「うまくいかないとき」の表つき（2026-09-27 時点の公式ヘルプで確認）。この実習には、Claude の有料プラン（Pro・Max・Team・Enterprise）と、その機能を使える権限が必要です。

Claude Code 入門ハンズオン 入門

非エンジニア向け ターミナル不要 Chat・Cowork との違い Step ごとに解説動画 80分進行表つき

Claude Desktop の Code タブで、お店の売上データ（CSV）を選ぶと合計と内訳が出る Web ページを、言葉で頼んで作ります。計画を先に見る・変更を 1 つずつ承認する・9 月と 10 月の 2 つの売上データで合計を確かめる、の順に進め、最後に自分の作業から道具にするものを 1 つ選んで頼み方を書きます。Chat・Cowork・Claude Code の違いの比較表つき（2026-10-04 時点の公式ドキュメントで確認）。この実習には、Claude の有料プラン（Pro・Max・Team・Enterprise）と、その機能を使える権限が必要です。
