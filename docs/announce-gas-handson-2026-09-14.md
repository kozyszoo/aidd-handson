## 補足: クレジットカードが要らなくなった

告知文に「必要なもの: Google アカウント」と書いているが、**2026-09-02 まで教材の Step 2 は Google Cloud のアカウント作成とクレジットカード登録を求めていた**。告知と教材が食い違っていた。

調べたところ、この工程はこの教材では不要だった。

- 教材でメール送信に使っているのは `MailApp.sendEmail` だけ
- `MailApp` は Apps Script の標準サービスで、Cloud プロジェクトも Gmail API の有効化もカード登録も要らない（[公式ドキュメント](https://developers.google.com/apps-script/reference/mail/mail-app)）
- 初級編・発展編を全文検索したが `GmailApp` も Gmail API も一度も使われていない

ユーザーの判断で Step 2 を削除した。**告知文の記述はそのままで正しい。**
