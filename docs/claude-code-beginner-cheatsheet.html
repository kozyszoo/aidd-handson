Claude Code 入門 チートシート

付録 ／ 売上データを選ぶと合計と内訳が出る Web ページを、言葉で頼んで作る（Code タブ・練習用データ）

表面 ・ ハンズオンの要点

1. 最初の設定 Step 1

設定選ぶもの
実行場所Local（自分のパソコンの上で動かす）
フォルダSelect folder →「売上ビューア」
権限モードManual（書き換える前・コマンドを実行する前に聞かれる）

Local でも、読んだ中身は答えを作るために AI へ送られる。作業フォルダには練習用のデータだけを入れる。

2. 権限モード 5 つ 古い版は名前が違う

Manual変更の前に聞く。Accept か Reject を選ぶ。今回これを使う
Plan調べて計画だけ出す。ファイルは変えない（Step 2）
Accept edits書き換えは聞かずに進む。慣れてから
Auto聞かずに進む。慣れてから
Bypass確認なしで進む。使わない

3. 進め方（解説動画 → ハンズオン） 各 Step

Step 0
アプリと練習用フォルダを用意する
Step 1
フォルダを開き、中身を説明してもらう（読むだけ）
Step 2
Plan にして、作る前に計画を出してもらう
Step 3
Manual で承認してページを作り、開いて合計を確かめる
Step 4
並び順・絞り込み・見出しを、言葉で頼んで直す
Step 5
10 月のデータで試し、合計が合うか確かめる
Step 6
データを外へ送っていないか確かめ、5 つの約束を見る
Step 7
自分の作業から 1 つ選び、頼み方を書く

4. お願い文の型 Step 2・7

【作りたいもの】売上明細（CSV）を読み込んで、売れ行きを見られる Web ページ
【入れるもの】「販売日・商品・金額」の 3 列の CSV。ページの「ファイルを選ぶ」ボタンで選ぶ
【出てくるもの】合計金額と件数／商品ごとの合計（棒グラフ）／売上の表
【決まりごと】index.html の 1 つだけ／外のインターネットの部品は使わない／入れたデータをどこにも送らない・保存しない／元のデータは書き換えない／何もインストールしない
【確かめ方】合計が、答えが分かっているデータの数字と同じか
【進め方】まだファイルは作らず、先に計画を出す

5. 計画を見たら確かめる 4 つ Step 2

  1. 作るファイルが index.html の 1 つだけか
  2. インストール・ダウンロードが書かれていないか。あれば「インストールなしで作れる方法にしてください」と返す
  3. CSV の読み込みが「ページのボタンでファイルを選ぶ」形か
  4. 分からない言葉は、そのまま聞く（「高校生に分かる言葉で説明してください」）

6. 直したあとの 3 つの確認 Step 4

  • Accept の前に、変えるファイルが index.html かを見る
  • ページを読み込み直し、9 月の CSV を選び直して、頼んだところが変わっているかを見る
  • 合計が 9,440 円のままかを見る（直すたびに、答えが分かっている数字を 1 つ見直す）

7. 確認の画面で読む 2 か所 Step 3

読むところAcceptReject
変えるファイル「売上ビューア」の中の index.html を作るCSV を書き換えようとしている／フォルダの外の場所が出ている
コマンドの実行実行がない。または、何のためか聞いて納得できた何かをインストールしようとしている／何のためか分からない

Reject すると理由を聞かれる。「なぜ必要ですか。使わない方法はありますか」と返す。

8. 答え合わせの数字 Step 3・5

売上明細件数合計
9 月分6 件9,440 円
10 月分5 件18,260 円

9 月: ギフトセット 5,600／焼き菓子セット 1,650／ブレンドコーヒー 1,200／豆の定期便 990
10 月: ギフトセット 12,800／ランチセット 3,250／ブレンドコーヒー 1,220／豆の定期便 990

合計が 5,472 円なら：10 月の "12,800"（カンマ入り）を「12」と「800」に分けて読んでいる。正しい数字を伝え、原因の説明と直しを頼み、9 月も確かめ直す。

9. 使うときの 5 つの約束 Step 6

  1. フォルダは、道具ごとに 1 つ。練習用のデータだけ入れる。本物の売上データは作業フォルダに入れない
  2. Manual で、変更を 1 つずつ見る。分からない確認は Reject して理由を聞く
  3. 作る前に、計画と決まりごとを見る。毎回お願いに書く（または CLAUDE.md）
  4. 答えが分かっているデータで確かめる。形の違うデータを 2 種類以上。直したら前の数字も見直す
  5. 人に渡す前・仕事で使う前に、確認を取る。会社や学校のデータは組織のルールを確認する

Claude Code 活用ガイド

付録（裏面）／ ハンズオンの先へ。普段使いの便利な使い方を、場面ごとに早見

裏面 ・ 活用全般

使える場所: DesktopClaude Desktop の Code タブ ／ CLIターミナル版 ／ 両方。 画面の名前・キーは版や OS で変わる（キーは Mac の場合。Windows は公式ドキュメントで確認）。

A. 指示の出し方

具体的に頼む 両方対象・場所・できあがりの基準を書く。例「ログイン画面で、入力が空のときは赤字で『入力してください』と出す。動かして確かめて」
先に計画だけ 両方Plan を選ぶ（Desktop は送信ボタン横の切り替え。CLI は Shift+Tab）。変更の前に方針を出させ、確認してから進める
ファイルや画像を渡す 両方入力欄の「+」で添付、またはドラッグ＆ドロップ。@ とファイル名で、そのファイルを文脈に入れる。画面の写真は文章より正確に伝わる
途中で止める 両方停止ボタンか Esc。それまでの作業は残る。実行中に修正文を送ってもよい
会話が長くなったら 両方話題が変わったら /clear。要約して続けるなら /compact。同じ指摘を 2 回しても直らないなら、新しい会話で頼み直すほうが速い

B. 安全に使う

権限モード 両方最初は Manual（毎回聞かれる）。Bypass は使い捨ての環境だけ
差分の画面 Desktop変更後の「+12 -1」のような表示をクリックすると、変わった行の一覧が出る。行をクリックしてコメントを書き、まとめて送って直させる
巻き戻し CLI入力欄が空のとき Esc を 2 回、または /rewind。ただし rm・mv など、コマンドで消した・動かしたものは戻らない。Desktop で戻す方法は、公式の記載を確認できなかった
Git で区切る 両方「変更を分かりやすい名前で commit して」と頼む。区切りごとに残しておけば、前の状態に戻せる。「新しいブランチを作って」で作業を分けられる

C. 覚えさせる・ルールを決める

CLAUDE.md 両方毎回守ってほしい決まりを書く 1 つのファイル。/init で雛形を作る。「CLAUDE.md に追記して」と頼んでもよい
自動メモリ 両方「これを覚えておいて」と頼むと、次の会話でも参照される。オン・オフの切り替えは CLI の /memory
スキル 両方よくやる手順を SKILL.md に書くと、/名前 で呼び出せる。入力欄で / を打って選ぶ（Desktop は「+」→ Slash commands でも）
フック 両方「編集のたびに必ず実行」など、例外なく動かしたい処理を設定ファイルに書く。上級者向け。Desktop で動くかは公式の記載を確認できなかった

D. 作業を広げる

複数の作業を並べる Desktop「+ New session」（Cmd+N）で作業ごとにセッションを分ける。Git のフォルダなら、ブランチ名の横の worktree（ファイルが衝突しない別コピー）で並行できる。CLI は claude --worktree 名前
Cloud で任せる Desktop環境を Cloud にすると、アプリやパソコンを閉じても作業が続く。進み具合は claude.ai/code やスマホのアプリで見て、途中で指示を変えられる
画面のプレビュー DesktopCmd+Shift+B で Browser pane を開くと、Claude が起動したアプリを右側で見ながら直せる
コネクタ Desktop入力欄の「+」→ Connectors で、Google カレンダー・Slack・Notion などをつなぐ。CLI は claude mcp add（上級者向け）
決まった時刻に実行 DesktopRoutines →「New routine」→ Local。毎時・毎日・平日・毎週から選ぶ。アプリが開いていて、パソコンが起きている必要がある

E. 困ったとき・使用量の管理

使用量を見る 両方Desktop は入力欄の横、モデル名の隣の輪（usage ring）をクリック。CLI は /usage。上限に当たる前に、作業の量を調整できる
モデルを選ぶ 両方簡単な作業は軽いモデル、難しい設計は重いモデル。公式は「多くの作業は Sonnet で足りる。Opus は複雑な設計向け」。CLI は /model
上限・エラー 両方「session limit」は、再開の時刻まで待つ（/usage で確認）。「Prompt is too long」は /compact か /clear で会話を短くする。エラー文は、そのまま Claude に見せる
使い方を聞く 両方「Claude Code で〜はできる？」と聞くと、公式ドキュメントを見て答える。CLI は /help で一覧が出る

F. ターミナル版の入口 次に進みたい人向け

起動 CLIcd 作業フォルダ のあと claude。初回はブラウザでログイン
1 回だけ聞く CLIclaude -p "このフォルダの概要を説明して"（会話を始めず、結果だけ受け取る）
前の続き CLIclaude --continue（直近）／ claude --resume（一覧から選ぶ）。Desktop は左のサイドバーの一覧から選ぶ
基本の 3 つ CLI/help（一覧）・/clear（会話を空にする）・/exit（終了）。Shift+Tab でモード切り替え（Desktop では使えない）
