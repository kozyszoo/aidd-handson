🧰 Claude Code 入門ハンズオン
～ 売上データを読み込んで、売れ行きが見える 1 枚のページを作る ～

Claude Code は、プログラムを書く AI です。この資料では、Claude Desktop アプリの Code タブを使い、お店の売上データ（CSV）を選ぶと合計と内訳が出る Web ページを、言葉で頼んで作ります。黒い画面（ターミナル）は使いません。プログラムを自分で書くこともありません。

所要時間: 約 120 分（解説動画 約 31 分＋ハンズオン）／ 前提: Claude の有料プラン（Pro・Max・Team・Enterprise）と Claude Desktop アプリ。Node.js やターミナルの準備は要りません ／ Claude の利用は 18 歳以上が対象 ／ 内容は 2026-10-04 時点の公式ドキュメントで確認

🙋 みなさんの進捗状況を知りたいので、うまく進んでいる場合も、進んでいない場合も絵文字リアクションを積極的に返してください！進んでないよ、というときも遠慮なく！

はじめに

Chat・Cowork・Claude Code の違い

Claude Desktop アプリには、Chat・Cowork・Code の 3 つがあります。どれも同じ Claude ですが、渡すものと、返ってくるものが違います。同じお店の売上データを題材にして比べます。

この資料群で扱うページ―Claude Cowork 活用ハンズオンClaude Code 入門ハンズオン

3 つは、同じ Claude Desktop アプリの中にあります。2026 年 9 月から、一部のアカウントでは Chat と Cowork が 1 つの画面にまとまり、同じ入力欄に書くと Claude が必要に応じてファイル作業を始める形になっています（公式ヘルプ「Claude Cowork and chat are one Claude」）。

🔁 来月、同じ作業が来たとき

毎月同じ形のデータに同じ処理をするなら、道具を 1 つ作っておくと、次からは AI に頼まずに済みます。そのかわり、道具が正しく動くかを確かめるのは自分です。この資料の後半（Step 5・6）は、その確かめ方に時間を使います。

🛠️ 出てくる言葉を、お店の例えで先に知る

この資料には、初めて見る言葉がいくつか出てきます。先に「注文を受けて道具を作ってくれる、町の工房」の例えで押さえておくと、Step 1 以降が読みやすくなります。例えは目安です。くわしい動きは、各 Step で説明します。

Step 0: アプリと練習用フォルダを用意する

🎬 ① 先に解説動画を見る（約 2 分 43 秒） ― やることと確かめるところを、先につかみます。見終わったら、下の手順で ② 手を動かします。動画を開く（Google Drive）

📋 必要なもの

必要なもの確認のしかた
Claude の有料プランPro・Max・Team・Enterprise のどれか。無料プランでは Code タブは使えません
Claude Desktop アプリmacOS か Windows。claude.com/download から入れて、ログインしておきます。すでに入っている人は、最新版に更新しておきます
インターネット接続作業中はずっとつながっている必要があります
練習用フォルダ下のボタンからダウンロードします

公式ドキュメントには「デスクトップアプリに Claude Code が入っているので、Code タブを使うために Node.js やコマンドライン版を入れる必要はない」と書かれています。ほかのソフトを入れる手順はありません。

📥 練習用フォルダをダウンロードする

練習用フォルダ（claude-code-practice.zip）をダウンロード

  1. ダウンロードした zip を開いて（展開して）、「売上ビューア」フォルダを取り出す
  2. デスクトップなど、すぐ見つかる場所に置く
  3. 中に次の 2 つのファイルがあることを確かめる
売上ビューア/
├── 売上明細_202609.csv   ← 9 月分（6 件）。Step 3 で使う
└── 売上明細_202610.csv   ← 10 月分（5 件）。Step 5 で使う

CSV は、表の中身をカンマ区切りの文字で保存したファイルです。レジや会計ソフトから書き出した売上データは、多くがこの形です。中身はすべて架空のものです。

ℹ️ なぜ専用のフォルダを使うのか。 Code タブで選んだフォルダは、Claude の作業場所になります。Claude はその中のファイルを読み、新しいファイルを作り、書き換えます。デスクトップ全体や書類フォルダ全体を選ばず、作る道具ごとにフォルダを 1 つ用意し、要るデータだけをコピーして入れます。

Step 1: Code タブでフォルダを開き、中身を説明してもらう

  3. 次のお願いを貼り付けて送る
設定するもの選ぶもの意味

🤖 Claude Code にこう頼む
このフォルダにあるファイルを一覧にして、それぞれに何が入っているかを日本語で説明してください。 2 つの CSV は、列の名前・件数・金額の合計も教えてください。 ファイルの変更や新しいファイルの作成はしないでください。

📋 返ってきた答えで見るところ

  • 9 月分が 6 件・合計 9,440 円、10 月分が 5 件・合計 18,260 円と答えているか
  • 列の名前が「販売日・商品・金額」になっているか

この 2 つの合計は、あとで道具が正しく動くかを確かめるときの答えとして使います。メモしておいてください。

権限モードは 5 つある

Claude Code には、どこまで確認しながら進めるかを決める「権限モード」があります（公式ドキュメント「Choose a permission mode」）。

名前動き方このハンズオンでは
Manualファイルを書き換える前・コマンドを実行する前に聞く。変更の内容を見て、受け入れる（Accept）か断る（Reject）かを選ぶ。受け入れるまでファイルは変わらないこれを使う
Planファイルを読んで調べ、進め方の計画を出す。ファイルは書き換えないStep 2 で使う
Accept editsファイルの書き換えと、フォルダを作る・ファイルを移すなどの基本的なファイル操作は、聞かずに進める。それ以外のコマンドは実行の前に聞く慣れてから
Auto聞かずに進める。コマンドの実行や通信の前に、依頼に合っているかを別の仕組みが裏で確かめる慣れてから
Bypass permissions確認なしで進める。公式ドキュメントでは「隔離された環境の中だけで使う」とされている。Pro・Max では設定でオンにしない限り選択肢に出ない。Team・Enterprise では組織の管理者の設定で決まる使わない

古い版のアプリでは、Manual が「Ask permissions」、Accept edits が「Auto accept edits」、Plan が「Plan mode」と表示されます。

⚠️ Cowork との違い。 Local を選んだ Claude Code は、自分のパソコンの上で、ファイルを直接使って動きます。プログラムを動かすこともできます。Cowork 編で紹介した「プログラムの実行は、パソコンとは切り離された環境で行う」という守りは、ここにはありません。そのぶん、フォルダを絞ることと、Manual で 1 つずつ見ることが大事になります。
⚠️ Local は「ファイルの操作を自分のパソコンで行う」という意味です。「内容が外に出ない」という意味ではありません。 Claude が読んだファイルの中身は、答えを作るために Anthropic の AI へ送られます。Chat に貼り付けるのと同じです。そのため、作業フォルダには練習用のデータだけを入れます。本物の売上データは作業フォルダに入れず、道具ができあがってから、いつものブラウザで道具に読み込ませます（Step 6）。

🗺️ 計画

Step 2: 作りたいものを伝えて、先に計画を出してもらう

🎬 ① 先に解説動画を見る（約 3 分 57 秒） ― やることと確かめるところを、先につかみます。見終わったら、下の手順で ② 手を動かします。動画を開く（Google Drive）

いきなり作らせず、何をどう作るつもりかを先に見ます。公式ドキュメントでも、込み入った作業は Plan で進め方を出させてから実行に移すことが勧められています。

📋 手順

  1. 権限モードを Plan に切り替える
  2. 次のお願いを貼り付けて送る
🤖 Claude Code にこう頼む
このフォルダの売上明細（CSV）を読み込んで、売れ行きを見られる Web ページを作りたいです。 【入れるもの】 「販売日・商品・金額」の 3 列がある CSV。ページにある「ファイルを選ぶ」ボタンで選ぶ 【出てくるもの】 ・合計金額と件数 ・商品ごとの合計（棒グラフ） ・売上の表 【決まりごと】 ・作るファイルは index.html の 1 つだけにする ・インターネット上の部品（外部のライブラリやフォント）は使わない ・選んだ CSV の内容を、どこにも送らない・保存しない ・来月以降、同じ形の別の CSV を選んでも使えるようにする ・フォルダにある CSV は書き換えない ・パソコンに何かをインストールしない 【進め方】 まだファイルは作らないでください。作り方の計画と、私に確認したいことを、日本語で先に見せてください。

📋 計画を見たら確かめること

計画には、プログラムの言葉（HTML・JavaScript など）が出てきます。全部を理解する必要はありません。次の 4 つだけを見ます。

  • 作るファイルが index.html の 1 つだけになっているか
  • 何かをインストールする・ダウンロードすると書かれていないか。書かれていたら「インストールなしで作れる方法にしてください」と返す
  • CSV の読み込み方が「ページのボタンでファイルを選ぶ」になっているか
  • 分からない言葉があれば、そのまま聞く。例:「FileReader とは何ですか。高校生に分かる言葉で説明してください」

Claude から質問が返ってきたら、答えます。迷う質問には「おすすめの方でお願いします。理由も教えてください」と返して構いません。

Step 8: もっと便利にする機能（紹介のみ）

ハンズオンでは手を動かしませんが、慣れてきたら使える機能です。どれも 2026-10-04 時点の公式ドキュメントに載っているものです。使える条件はプランや組織の設定で変わるので、試す前に公式ドキュメントを確認してください。

機能できること
CLAUDE.mdフォルダに置いておく、Claude へのルールを書いたファイル。「説明は日本語で」「インターネット上の部品を使わない」「インストールしない」などを書いておくと、毎回のお願いに書かなくても読まれる。「このフォルダ用の CLAUDE.md を作ってください。ルールは次のとおりです」と頼めば作れる
差分の画面（diff view）Claude がファイルを変えたあとに出る「+12 -1」のような表示を押すと、どのファイルの何行目が変わったかを一覧できる。行を押してコメントを書き、直しを頼める
ファイルや画像を添付する入力欄に画像や PDF を貼り付けて、「この見本と同じ見た目にして」のように頼める
使用量の表示モデルを選ぶ欄の近くにある輪の表示を押すと、今の会話とプランの使用量を見られる
Cloud で動かすLocal のかわりに Cloud を選ぶと、Anthropic 側の環境で動き、アプリを閉じても作業が続く
スケジュールタスク決まった時間に、同じ作業を自動で行う
コネクタ・プラグイン入力欄の「+」から、外のサービスとの連携や追加の機能を入れられる。Step 6 の注意のとおり、提供元が分かるものを 1 つずつ足す
ターミナル版黒い画面（ターミナル）で同じ Claude Code を使う。Git やテストなど、開発の作業をする人向け。Claude Code ハンズオンガイド（エンジニア向け）で扱う

講師向け: 進行のめやす（120 分版）

各 Step は「解説動画 → ハンズオン」の順です。動画は全員が同時に見られるよう、講師の画面を投影して流すか、各自の画面で一斉に再生します。

時間内容講師がすること
0:00〜0:10はじめにCowork と Code の違いを図で説明する。Cowork 編に出た人を挙手で確認する。「動画 → ハンズオン」の進め方と、音が出るか（イヤホン）を確認する
0:10〜0:22Step 0（動画 3 分＋ハンズオン 9 分）アプリの更新が済んでいるかを確認する。有料プランでない人は、隣の人と組んで画面を見る形にする
0:22〜0:36Step 1（動画 4 分＋ハンズオン 10 分）Local・Select folder・Manual の 3 つを、講師の画面で 1 つずつ見せる。9,440 円と 18,260 円をメモしてもらう
0:36〜0:50Step 2（動画 4 分＋ハンズオン 10 分）Plan に切り替えるところを見せる。返ってきた計画から「作るファイルの名前」と「インストールの有無」を探すところを、声に出して実演する
0:50〜1:09Step 3（動画 4 分＋ハンズオン 15 分）確認の画面を全員の前で見せ、「どのファイルに」「何を」を読んでから Accept を押す。9,440 円が出た人を挙手で数える
1:09〜1:23Step 4（動画 4 分＋ハンズオン 10 分）直したあとに合計を見直すところまでを 1 回実演する
1:23〜1:37Step 5（動画 4 分＋ハンズオン 10 分）18,260 円が出た人・5,472 円が出た人・エラーになった人を挙手で数える。全員が合っていた場合も、CSV の「"12,800"」の行を画面に出して、なぜ試す必要があるかを説明する
1:37〜1:46Step 6（動画 4 分＋ハンズオン 5 分）確かめるお願いを送ってもらい、5 つの約束の表を、Step 1〜5 で起きたことと結び付けて説明する
1:46〜2:00Step 7・まとめ（動画 4 分＋ハンズオン 10 分）動画のあと、ひな形を書いてもらう（8 分）。残りの 2 分で、1〜2 人に選んだ作業と「確かめ方」を発表してもらい、Step 8 とチェックリストの場所を案内する

進行で気をつけること

  • 解説動画は、最後まで流してから手を動かす。途中で止めて質問を受けると、全体が 120 分に収まらなくなる。質問はハンズオンの時間に受ける。動画の語りは、画面に出ていることを話している。速いと感じる人には、動画を再生しながら手を動かすのではなく、見終わってから手順に戻るよう伝える
  • 当日の前に、動画が全員の環境で再生できるかを確かめる。動画は Google Drive にある。共有の設定を事前に確認し、音が出ない人には、画面の文字を読みながら見てもらう
  • 当日の前に、講師の画面で Step 1〜6 を一度通しておく。ボタンの名前や場所がこの資料と違っていたら、その場で読み替えを伝える。権限モードの名前は版によって違う（Step 1 の表の下を参照）
  • 作られるページは、人によって見た目が違う。同じお願いでも、色・配置・グラフの形は毎回変わる。そろえるのは見た目ではなく、合計の数字であることを最初に伝える
  • Step 5 で全員が正しく読めることがある。その場合も失敗ではない。「試したから合っていると分かった」ことを伝える
  • プログラムの中身の説明に入りすぎない。質問が出たら、「Claude に、高校生に分かる言葉で説明してと頼む」やり方を見せる
  • Accept edits・Auto・Bypass permissions を勧めない。質問が出たら、Step 1 の表で違いを説明する
  • 使用量の上限に達した人がいたら、完成見本のページを開いてもらい、Step 5 の確かめ方だけ体験してもらう
  • Step 7 では、本物のデータを入れさせない。書くところまでで止める
  • 「🧯 うまくいかないとき」を先に案内する。表にないことが起きたら、次回のために書き留める

おわりに

このハンズオンでは、Claude Desktop の Code タブで「売上ビューア」フォルダを開き、計画を先に見てから、売上データを集計するページを 1 つ作りました。9 月と 10 月の 2 つの売上データで合計を確かめ、データを外へ送らないことを確かめ、使うときの 5 つの約束にまとめました。

自分の道具を作るときは、フォルダを 1 つ作り、形だけ同じにした練習用のデータを入れ、Step 7 で書いた頼み方を Plan で送るところから始めてください。
