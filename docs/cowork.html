チャットは、質問や、1 つずつ添付したファイルに答えるものです。Claude Cowork は、渡したフォルダの中のファイルを読み、整理し、新しい Excel や Word を作って置くところまでやります。この資料では、よくある「散らかったダウンロードフォルダ」の練習用コピーを使ってその作業を体験し、あわせて任せるときに気をつけることを確認します。

はじめに

Cowork は何をするものか

Anthropic の公式ヘルプでは、Cowork は「Claude Code と同じエージェントの仕組みを、プログラミング以外の仕事に使えるようにしたもの。ターミナルは要らない」と説明されています。複数の手順がある作業をまとめて任せ、終わったころに戻ると、整った文書や整理済みのファイルができている、という使い方です。

💬 チャットと Cowork の違い

便利になるのと同時に、AI があなたのファイルを実際に書き換えられるようになります。チャットでは「変な答えが返る」で済んでいた失敗が、Cowork では「ファイルが消える」「外へ送られる」につながりえます。この資料の後半（Step 5・6）は、そのための約束に時間を使います。

Chat・Cowork・Claude Code の違い

Claude Desktop アプリには、Chat・Cowork・Code の 3 つがあります。どれも同じ Claude ですが、渡すものと、返ってくるものが違います。このハンズオンで使うお店の売上データを題材にして比べます。

必要なもの確認のしかた

📥 練習用フォルダをダウンロードする

このハンズオンでは、自分の本物のファイルは使いません。かわりに、よくある「散らかったダウンロードフォルダ」を再現した練習用フォルダを使います。中身はすべて架空のものです。

練習用フォルダ（cowork-practice-downloads.zip）をダウンロード

🚪 最初の一歩

Step 1: フォルダを渡して、中身を説明してもらう

最初は読むだけのお願いにします。ファイルを書き換えないので、何が起きても元に戻す必要がありません。

📋 手順

  1. Claude Desktop アプリを開く
  2. 画面が切り替わっていない人は、入力欄で「Cowork」を選ぶ（切り替わった人はそのまま）
  3. 「練習用ダウンロード」フォルダを、Finder（Mac）やエクスプローラー（Windows）から Claude の画面へドラッグ＆ドロップする。入力欄の近くにあるフォルダを選ぶボタンから選んでも構いません
  4. フォルダへのアクセスを求められたら、「練習用ダウンロード」であることを確かめてから許可する
  5. 次のお願いを貼り付けて送る
🤖 Cowork にこう頼む
渡したフォルダの中にあるファイルを一覧にして、それぞれ何が書いてある（写っている）かを一言で説明してください。 あわせて、パスワードや身分証など、人に見られると困りそうなファイルがあれば教えてください。 ファイルの変更や新しいファイルの作成はしないでください。

📋 返ってきた答えで見るところ

  • 画像や PDF の中身まで説明されているか。IMG_2031.jpg が「ドラッグストアのレシート」、document.pdf が「粗大ごみ収集の案内」と分かれば、ファイルを開かなくても中身をつかめています
  • wifi_パスワード.txt と 本人確認書類_スキャン.png が「見られると困る」として挙がっているか

2 つ目が、この Step でいちばん大事なところです。指摘されたということは、Claude はもうその中身を読んでいるということです。渡したフォルダの中は全部読まれる。本物のダウンロードフォルダを渡す前に、こうしたファイルを外に出しておく必要があります。

⚠️ 許可の画面は、読まずに押さない。 「どのフォルダか」「何をしようとしているか」が書いてあります。練習用ダウンロード以外の名前が出たら、許可せずに止めてください。

任せ方（承認モード）を「Manual」（従来の画面では「Manually approve」）にしておく

入力欄の承認設定は、チャットとまとまった新しい画面では「Manual」と「Auto」の2種類、従来の画面では「Manually approve」「Automatically approve」「Skip all approvals」の3種類があります（新しい画面には Skip all approvals はありません）（公式ヘルプ「Get started with Claude Cowork」）。

設定の名前動き方このハンズオンでは
Manual（従来の画面: Manually approve / 手動で承認）操作の前に止まって、許可するかをあなたに聞くこれを使う
Auto（従来の画面: Automatically approve / 自動で承認）止まらずに進める。そのかわり操作ごとに Claude が安全かを確かめ、危ないと判断したものは止める。安全の確認をする分、使用量を多く使う慣れてから
Skip all approvals（従来の画面のみ / すべて確認しない）止まらず、自動の安全確認もしない。公式ヘルプでは「関わるアプリや連携先を完全に信頼できるときだけ」とされている使わない

このハンズオンでは Manual（従来の画面では Manually approve）を選びます。Claude が何をしようとしているかを一つずつ見ます。「こういう順番で作業するのか」が分かってから、次の設定を考えれば十分です。

🧯 うまくいかないとき
起きていること直し方
フォルダをドラッグしても何も起きない入力欄の近くにあるフォルダを選ぶボタンから「練習用ダウンロード」を選びます
許可の画面に、練習用ダウンロード以外の名前が出た許可せずに止めます。上の階層（デスクトップなど）を選んでしまっています。フォルダを選び直します
画像や PDF が、ファイル名だけで説明されている「画像と PDF は中身を開いて読み、何が書いてあるかを説明してください」と続けて送ります
送ったあと、止まったまま動かない許可を待っていることがあります。画面に確認のボタンが出ていないかを見ます。出ていなければ、止めて同じお願いをもう一度送ります
頼んでいないのにファイルを作った・名前を変えた練習用フォルダなので、消して zip から展開し直せば元に戻ります。次のお願いから「変更はしないでください」の 1 行が入っているかを確かめます

🧹 整理

Step 2: 種類と用途ごとにフォルダ分けし、重なったファイルを片付ける

公式ヘルプでも最初の例に挙がっている「ダウンロードフォルダを種類と日付で整理する」をやってみます。ポイントは、いきなり動かさず、先に計画を見せてもらうことです。

🤖 Cowork にこう頼む
このフォルダを整理してください。 ・「お金」「手続き・申込」「その他」の 3 つのフォルダを作って分ける ・ファイル名を、中身が分かる「YYYYMMDD_内容」の形にそろえる（日付は書類の中の日付を使う） ・中身がまったく同じファイルがあれば、消す候補として挙げる ・パスワードや身分証のファイルは動かさず、そのままにする まだファイルは変更せず、「今の名前 → 新しい場所と名前」の一覧と、消す候補を先に見せてください。私が OK と言ってから実行してください。

📋 計画を見たら確かめること

  • document.pdf と document (1).pdf に、中身に合った名前（粗大ごみ・設備点検）が付いているか
  • 消す候補が スクリーンショットの (1) だけになっているか。document (1).pdf は名前が似ているだけで、中身は別の書類です。これを消す候補にしていたら、計画の段階で止めて直してもらいます
  • wifi_パスワード.txt と 本人確認書類_スキャン.png が動かされていないか

問題がなければ「OK です。実行してください」と送ります。

⚠️ 削除の前には、必ず確認の画面が出ます。 公式ヘルプでは「ファイルを完全に削除する前に、Claude は必ずあなたの明示的な許可を求める。許可の画面で『Allow』を選ぶまで削除は行われない」とされています。削除を聞かれたら、消すファイルの名前を読んでから許可してください。
ℹ️ 必ず止まるのは「完全な削除」だけです。 名前の変更・移動・上書きは、Automatically approve に切り替えていると止まらずに進みます。本物のフォルダで整理を頼むときは、先にコピーを取っておくか、この Step と同じように「一覧を先に見せて、OK してから実行」と頼んでください。
🧯 うまくいかないとき
起きていること直し方
一覧を見せずに、すぐファイルを動かし始めた止めるボタンで止めます。フォルダを消して zip から展開し直し、お願いをもう一度送ります
document (1).pdf が消す候補に入っている「document.pdf と document (1).pdf は中身を開いて比べてください。別の書類なら消す候補から外してください」と返します
新しい名前の日付が、今日の日付になっている「日付は書類の中に書いてある日付を使ってください。書いていなければ日付を付けないでください」と返します
実行したあとで、元の状態に戻したいフォルダを消して zip から展開し直します。本物のフォルダではこの戻し方が使えないので、先にコピーを取ります

📅 拾い出す

Step 3: バラバラの書類から「期限があるもの」を一覧にする

返却期限はスクリーンショットに、申込の締切は PDF に、自分のやることはメモに書いてあります。ばらばらの形のファイルを 1 つずつ開いて期限を拾うのは、人がやると手間のかかる作業です。これを Cowork に任せます。

🤖 Cowork にこう頼む
フォルダの中の画像・PDF・メモをすべて見て、期限や日付が決まっている「やること」を拾い出し、「期限一覧.xlsx」を作ってください。 列は「期限 / やること / 金額（あれば）/ どのファイルに書いてあったか」にして、期限が近い順に並べてください。 ファイルに書いていないことは推測で埋めず、空欄にしてください。

📋 できたファイルを自分で開いて確かめる

作られた Excel は、Claude の画面の会話の横に表示されます。必ず自分で開いて、元のファイルと見比べてください。

Step 4: 売上データ・レシートの写真・スマホ料金から、9 月のお金の出入りをまとめる

公式ヘルプでも「レシートをフォルダに入れて、経費の報告書を作ってもらう」「数式の入った Excel を作る」といった使い方が例に挙がっています。ここでは、お店の売上データ（CSV）・レシートの写真・スマホ料金の PDFという、形の違う 3 つをまとめて 1 つの表にします。売上は「入ってきたお金」、レシートとスマホ料金は「出ていったお金」です。

🤖 Cowork にこう頼む
売上明細（CSV）、レシートの写真、スマホ料金の PDF から、9 月のお金の出入りをまとめた「9月のお金の出入り.xlsx」を作ってください。 ・1 枚目のシート: 1 件ずつ「日付 / 内容 / 金額 / 入金か出金か / 元のファイル」 ・2 枚目のシート: 入金の合計、出金の合計、差し引き（入金 − 出金）。合計は手で書いた数字ではなく、Excel の数式で計算してください ・まだ払っていないもの（これから払う予定のもの）は入れないでください。何を入れなかったかも教えてください

📋 数字は自分で 1 つ確かめる

AI は読み取りや計算を間違えることがあります。全部を確かめる必要はありませんが、一番大事な数字を 1 つだけ自分で確かめる習慣をつけましょう。

💡 答え合わせ（開く前に自分で計算してみる）
  • 売上データ（入金）: 2,480 + 580 + 990 + 1,650 + 3,120 + 620 = 9,440 円（6 件）
  • レシートの写真（出金）: 398 + 298 + 690 = 1,386 円（現金払い）
  • スマホ料金・9 月分（出金）: 3,278 円
  • 出金の合計: 1,386 + 3,278 = 4,664 円
  • 差し引き: 9,440 − 4,664 = 4,776 円

判断が分かれるところ:

  • 講座の受講料 8,000 円は、まだ払っていないので入らないのが正解です。入っていたら、指示を読み落としています
  • スマホ料金は「9 月分」の料金ですが、引き落としは 10/27 です。入れるか入れないかは、どちらにも理由があります。Claude がどちらにしたか、その理由を説明しているかを見てください。決めるのはあなたです

Excel のセルをクリックして、数字ではなく =SUM(...) のような式が入っているかも確かめてください。式になっていれば、あとで 1 件直したときに合計も変わります。

ℹ️ 使用量について。 公式ヘルプ（Claude Enterprise consumption guide）では、Cowork のタスクは中で多くの手順を踏むため、1 回でチャットよりずっと多くの使用量を使うことがあると説明されています。チャット・Claude Code・Cowork は同じ使用上限を分け合っています。ハンズオン中に上限に達したら、講師に声をかけてください。

Step 5: 保存した Web ページの隠れた指示で、AI がだまされるか試す

ダウンロードフォルダには、Web ページやメールの添付など、外から来たファイルが集まります。その中に、AI に向けた指示がこっそり書かれていることがあります。

このように、AI が読むファイルやメール、Web ページの中に指示を仕込んで、AI を乗っ取ろうとする手口を「プロンプトインジェクション」と呼びます。公式ヘルプ「Use Claude Cowork safely」でも、Cowork の主なリスクとして最初に挙げられ、Web の内容が主な入り口だとされています。

  3. そのファイルを「練習用ダウンロード」フォルダへ移す
  4. 次のお願いを送る

Step 5 用のファイルをダウンロード

結果起きたこと

Step 6: 安全に使うための 5 つの約束

ここまでの体験を、本物のファイルで使うときの約束にまとめます。どれも公式ヘルプ「Use Claude Cowork safely」「Get started with Claude Cowork」に書かれている内容をもとにしています。

約束このハンズオンで見たこと本物のファイルで使うときにやること
1. 渡すフォルダは、作業に要るものだけにするStep 1: パスワードと身分証のファイルが、渡した時点で読まれていたClaude 専用の作業フォルダを作り、要るファイルだけコピーして入れる
2. 取り返しのつかない操作は、自分で押すStep 2: 一覧を先に見て、OK してから実行した。削除の前に確認の画面が出た送信・購入・公開・削除がからむ作業は Manually approve（チャットとまとまった画面では「Manual」）にする。先にコピーを取る
3. 外から来たものは、指示として信じないStep 5: 保存した Web ページに、見えない指示が入っていた頼んでいないことを始めたら、止めて理由を聞く
4. できたものは、自分で開いて確かめてから使うStep 3・4: 元のファイルと見比べ、合計を計算し直した大事な数字を 1 つ計算し直す。元のファイルにないことが足されていないかを見る
5. 連携を広げるときは、1 つずつ・小さく始める（Step 8 で紹介する機能が対象）機能を 1 つ足すたびに、約束 1〜4 に当てはめて考える

それぞれの約束の理由と、公式ヘルプに書かれている内容は、下を開くと読めます。ハンズオンの中では表だけを確認し、くわしい説明はあとで読みます。

約束 1: 渡すフォルダは、作業に要るものだけにする（くわしく）
  • Cowork は、渡したフォルダの中のファイルだけを読み書きします。逆に言えば、渡したフォルダの中は全部読める・書き換えられると考えます。これはパソコンのフォルダについての話です。コネクタでつないだサービス、ブラウザ、画面の操作は、それぞれ別に許可した範囲にふれられます（Step 8）
  • 「ダウンロードフォルダ全体」「デスクトップ全体」「書類フォルダ全体」「ホームフォルダ」は渡さない。Claude 専用の作業フォルダを作り、要るファイルだけコピーして入れる
  • 次のものが入ったフォルダは渡さない: パスワードや API キー（外のサービスを使うための秘密の文字列）のメモ、銀行・給与・税金の書類、健康の記録、他人の個人情報（名簿・成績・住所）、会社や学校で「外に出さない」と決められた資料
  • 渡したフォルダは、Claude Desktop の 設定（Settings）→「Trusted folders」で一覧できます（チャットとまとまった新しい画面の場合）。使い終わったものは見直しましょう
約束 2: 取り返しのつかない操作は、自分で押す（くわしく）
  • 公式ヘルプでは、大事なファイル・アカウント・サイトにふれるときや、メッセージの送信や購入のように間違えると元に戻しにくいときは、手動承認（Manually approve）に切り替えるよう勧めています
  • 許可の画面では「どのファイルに」「何をするか」を読んでから押す。分からなければ拒否して、Claude に理由を聞く
  • 本物のフォルダを整理するときは、先にバックアップを取る。Step 2 のように「一覧を先に見せて、OK してから実行」と頼む
約束 3: 外から来たものは、指示として信じない（くわしく）
  • メール・Web ページ・もらったファイルは、Step 5 のようにAI への指示が隠れていることがある。公式ヘルプでは Web の内容が「プロンプトインジェクションの主な入り口」とされています
  • ブラウザの操作を任せるときは、信頼できるサイトだけにする
  • 作業の途中で、頼んでいないこと（別のフォルダを見る、外部へ送る、設定を変える）を始めたら、止めて理由を聞く。公式ヘルプでも、操作を一つずつ見るより作業全体に見慣れない動きがないかを見るよう勧めています
約束 4: できたものは、自分で開いて確かめてから使う（くわしく）
  • Step 3・4 でやったように、元のファイルと見比べる・大事な数字を 1 つ計算し直す。画像や PDF の読み取り間違いもある
  • 元のファイルにないことが、それらしく書き足されていないかを見る
  • 公式ヘルプには「Claude があなたの代わりに行った操作の責任は、あなたにある」とあります。送ったメッセージ・公開した内容・購入・定期実行したタスクの結果も含みます。「AI がやったから」は通らない前提で使います
約束 5: 連携を広げるときは、1 つずつ・小さく始める（くわしく）
  • 拡張機能・プラグイン: Claude Desktop の一覧にある確認済みのものを使い、求められる権限をよく見る
  • 画面の操作（Computer use）: 大事でない作業から始める。銀行・医療・出会い系などのアプリは、操作できる対象から外しておく。公式ヘルプでは、画面の操作はプログラムの実行のようには隔離されていないと説明されています
  • 定期実行（スケジュールタスク）: あなたが見ていない間に動くため、大事なファイルにふれる・あなたの名前でメッセージを送る・買い物をする作業は予約しない。過去の実行結果をときどき見返し、使っていないものは止める
  • 会社・学校で使うとき: まず組織のルールを確認する。Team・Enterprise では、管理者が Cowork を使えるかどうかや、つなげるアプリを決めています
ℹ️ Anthropic 側で用意されている守り（公式ヘルプより）: 怪しい指示を見分けて断るようにモデルを訓練している／入ってくる内容を調べて怪しい指示に印をつける仕組みがある／Automatically approve では操作の前に安全を確かめる／プログラムの実行は、あなたのパソコンとは切り離された使い捨ての環境で行う／ファイルの完全な削除は必ずあなたの許可を待つ。
それでも「必ず防げる」とは書かれていません。上の 5 つの約束は、仕組みで防ぎきれなかったときの被害を小さくするためのものです。
💡 AI に何を渡してよいかの考え方を、Cowork 以外のツールも含めて整理したいときは、個人でできる AI セキュリティ対策の「第2章: 何を渡すか」「第3章: 何をさせるか」を読んでください。

決めること書き方
渡すフォルダ新しく作る作業フォルダの名前と、そこへコピーして入れるファイル。パスワード・身分証・他人の個人情報・組織の「外に出さない」資料が入らないことを確かめる
最初に試すデータ本物ではなく、名前や金額を架空のものに置き換えた数件。請求書・アンケートの回答・議事メモ・写真には、他人の名前や連絡先が入っていることが多い。銀行・給与・税金・健康の書類は、本物を渡さない
確かめる数字や項目できあがりの中で、自分で元のファイルと見比べるものを 1 つ。例: 合計金額、一番近い期限、件数
承認モード最初は Manually approve（チャットとまとまった画面では「Manual」と表示されます）
💡 書いた頼み方を、Claude に見てもらう。 新しい会話を開き、フォルダを選ばずに、次の文の後ろへ自分の頼み方を貼って送ると、足りない情報を質問してもらえます。今までの会話には練習用フォルダが渡してあるので、そのまま続けて送らないようにします。 
次の依頼文を Cowork に送る予定です。まだ作業は始めないでください。この依頼文だけでは判断に迷う点を、質問として 3 つまで挙げてください。
⚠️ 会社や学校のファイルで試す前に、組織のルールを確認します。 AI に渡してよい情報の範囲が決められていることがあります。分からなければ、渡す前に上司や担当者に聞きます。
🧯 うまくいかないとき
起きていること直し方
作業が思いつかない上の表の例から 1 つ選びます。または、先週「ファイルを 3 つ以上開いて、1 つにまとめた作業」を思い出します
選んだ作業に、メール送信や申込が入っている「下書きを作る」「一覧にする」までを Cowork に頼み、送信や申込は自分でやる形に分けます
できあがりの形が決まらない今その作業で自分が作っているファイル（Excel の列、文書の見出し）をそのまま書きます

Step 8: もっと便利にする機能（紹介のみ）

ハンズオンでは手を動かしませんが、慣れてきたら使える機能です。使える条件がプランや画面によって違うので、表の右の列を見てから試してください。約束 5 のとおり、1 つずつ足していきます。

機能できること使える条件（2026-09-27 時点の公式ヘルプ）
コネクタGmail・Google Drive・Slack などとつないで、その中の情報を使って作業する有料プラン。つなげるアプリはプランや組織の設定による
ブラウザの操作Web ページを開いて調べる・入力する。Claude 専用のブラウザか、Chrome の拡張機能「Claude in Chrome」を使うPro・Max・Team（Enterprise は管理者が有効にした場合）
スケジュールタスク「毎朝」「毎週月曜」のように決まった時間に同じ作業を自動で行う有料プラン
プロジェクト関係する作業・指示・フォルダ・定期実行を 1 つの場所にまとめるDesktop・Web・スマホ。パソコンのフォルダに結び付けたプロジェクトで Cowork を使う場合は Desktop のみ
画面の操作（Computer use）Claude がパソコンの画面を見て、クリックや入力をする。コネクタやブラウザでできないときの最後の手段Pro・Max のみ。設定で自分でオンにし、アプリごとに許可する
Dispatchスマホから作業を頼み、パソコンの Claude に進めてもらうPro・Max。公式ヘルプでは限られた人向けの試験提供で、新しく使い始めることはできないとされている
スマホ・Web から使うclaude.ai やスマホアプリからも頼めるパソコンのファイル・ブラウザ・画面を使う作業は、Claude Desktop が起動していてつながっていることが条件。パソコンのフォルダを使う作業は、Desktopアプリで始めてフォルダを接続し、読み書きする間はアプリを開いておきます。その会話をWeb・スマホで開けば、続きを指示できます。
⚠️ 機能を足すほど、Step 5 の「①外から来た内容を読める」「②不利な操作ができる」が広がります。 メールをつなげば外から来た文章を読むようになり、ブラウザを任せればログイン中のサイトで操作できるようになります。足す前に、約束 1〜5 に当てはめて考えてください。

✅ チェックリスト

任せる前（毎回・30 秒）

  • ☐ 渡すのは、この作業に要るファイルだけが入ったフォルダか
  • ☐ パスワード・お金・健康・他人の個人情報・組織の秘密が入っていないか
  • ☐ 消えたら困るファイルは、コピーを取ったか
  • ☐ 送信・購入・公開・削除がからむなら、Manually approve にしたか
  • ☐ 外から来たファイル・メール・Web ページを読ませるか。読ませるなら、頼んでいない動きに気をつける

終わったあと（毎回・数分）

  • ☐ できたファイルを自分で開いて、元のファイルと見比べたか
  • ☐ 大事な数字を 1 つ計算し直したか
  • ☐ 頼んでいないファイルが増えたり、変わったり、消えたりしていないか

月に 1 回（10 分）

  • ☐ Trusted folders に、もう使わないフォルダが残っていないか
  • ☐ スケジュールタスクの実行結果を見返し、使っていないものを止めたか
  • ☐ つないだコネクタ・入れたプラグインで、使っていないものを外したか

講師向け: 進行のめやす（80 分版）

「説明 20 分 → 実践 40 分 → 共有 20 分」の 3 部構成です。成果は 2 つ（フォルダが種類ごとに片付く／9 月のお金の出入り表（Excel）ができる）で、どちらも画面で見て確かめられます。Step 5 は参加者が手を動かさず、講師の実演で見せます。

時間内容講師がすること
0:00〜0:08【説明】はじめにチャットと Cowork の違いを図で説明。参加者の画面が「Cowork を選ぶ画面」か「まとまった画面」かを挙手で確認する
0:08〜0:15【説明】Step 5 の実演講師の画面で、保存した Web ページの見えない一文を開いて見せ、AI がだまされる場面を実演する（参加者は見るだけ）。🍌 が出なかった場合も「見抜けたのは今回の結果で、いつもではない」と伝える
0:15〜0:20【説明】Step 6 の要点5 つの約束を、表の「このハンズオンで見たこと」の列を使って 1 分ずつ説明する。折りたたみの中は読み上げない。このあと渡すのは練習用フォルダだけであることを伝える
0:20〜0:25【実践】Step 0有料プランでない人・Desktop アプリが入らない人は、隣の人と組んで画面を見る形にする
0:25〜0:32【実践】Step 1ドラッグ＆ドロップを実演。許可の画面で「どのフォルダか」を声に出して読む。パスワードと身分証のファイルが指摘されたかを聞き、「指摘できた＝もう読まれている」を伝える
0:32〜0:42【実践】Step 2document (1).pdf を消す候補にされた人がいないか聞く。削除の確認画面を全員の前で見せ、「読んでから押す」を実演する
0:42〜0:50【実践】Step 3一番近い期限（10/3・画像の中）が拾えていたかを挙手で聞く
0:50〜1:00【実践】Step 4出金 4,664 円・差し引き 4,776 円を全員で確かめる。スマホ料金を入れた人・入れなかった人に分かれたら、どちらも理由があることを話す
1:00〜1:10【共有】Step 7自分の作業を 1 つ選んで、ひな形を書いてもらう（10 分）。本物のファイルは渡させない
1:10〜1:18【共有】発表3〜4 人に、選んだ作業と「確かめる数字」を 1 人 2 分で発表してもらう。発表したくない人は、隣の人にひな形を見せるだけでよい
1:18〜1:20【共有】まとめStep 8 とチェックリストの場所を案内する。Step 5 を手を動かして試したい人は、終わったあとに各自で行うよう伝える

進行で気をつけること

  • 本物のダウンロードフォルダを渡させない。「自分のファイルでも試したい」と言われたら、ハンズオンの後に、専用フォルダへコピーし、身分証・明細・パスワードのメモが入っていないのを確かめてからにしてもらう
  • Step 5 の結果は毎回変わりうる。モデルや安全の仕組みが更新されると、🍌 が出なくなることがあります。出なかった場合も「見抜けたのは今回の結果で、いつもではない」と伝える
  • Step 7 では、本物のファイルを渡させない。書くところまでで止める。会社のファイルで試したいと言われたら、組織のルールの確認が先であることを伝える
  • 「🧯 うまくいかないとき」を先に案内する。手が止まった人には、まず各 Step の終わりの表を開いてもらう。表にないことが起きたら、次回のために書き留める
  • Automatically approve や Skip all approvals を勧めない。質問が出たら、Step 1 の表で違いを説明する
  • 使用量の上限に達した人がいたら、隣の人の画面を見る形に切り替える
  • 2026 年 10 月 6 日より後に開催するときは、必ず通し直す。新しい作業がクラウドで動く形に変わるため、フォルダの渡し方・許可の画面・できたファイルの置き場所が、この資料（2026-09-27 時点）と違う可能性がある
  • 当日の前に、講師の画面で Step 1〜5 を一度通しておく。画面の切り替えが進んでいる時期なので、ボタンの名前や場所がこの資料と違っていたら、その場で読み替えを伝える

おわりに

このハンズオンでは、散らかったダウンロードフォルダの練習用コピーを渡して、中身の説明・フォルダ分け・期限の拾い出し・お金の出入りの集計を Cowork に任せました。あわせて、保存した Web ページの隠れた指示で AI がだまされる場面を試し、5 つの約束にまとめました。

自分のファイルで試すときは、専用の作業フォルダを 1 つ作り、要るファイルだけをコピーして入れるところから始めてください。
