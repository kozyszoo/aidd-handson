## 説明欄（connpass に貼る本文）

### このイベントについて

**Claude Code は、プログラムを書く AI です。** このハンズオンでは、Claude Desktop アプリの **Code タブ**を使い、**お店の売上データ（CSV）を選ぶと、合計と商品ごとの内訳が出る Web ページ**を、言葉で頼んで作ります。CSV は、表のデータをカンマ区切りの文字で保存したファイルです。

- 黒い画面（ターミナル）は使いません
- プログラムを自分で書くことはありません
- 使うデータは、練習用に用意した架空の売上データです
- Cowork（Claude に作業を任せる機能）を使ったことがなくても参加できます

作ったページは、練習用データと同じ列の形の CSV であれば、別の月のデータを選ぶだけで、同じ集計をもう一度出せます。「毎月同じ形のデータに、同じ処理をする」作業を、AI に頼まずに繰り返せる道具にする、という使い方を体験します。実際の仕事で使う前には、データの形式・計算結果・所属先のルールを確かめる必要があります。この確かめ方も、ハンズオンの中でやります。

### こんな方に向いています

- プログラミングをしたことがない
- Chat は使ったことがあるが、Cowork や Claude Code との違いが分からない
- 毎週・毎月、同じ形のデータを集計している
- AI に任せるとき、どこを自分で確かめればよいかを知りたい

### 参加するために必要なもの

**実習に参加する方は、当日までに次の 3 つを用意してください。**

1. **Claude の有料プラン**（Pro・Max・Team・Enterprise のどれか）。**無料プランでは Code タブを使えません。** プランの料金は、このイベントの参加費に含まれません
2. **Claude Desktop アプリ**（macOS か Windows）。インストールしてログインし、**最新版に更新**してください。スマホやタブレットのアプリでは、実習はできません
3. **パソコン**と、途中で切れないインターネット接続。動画の音声が出るので、イヤホンかスピーカーも用意してください

そのほか:

- **Claude の利用は 18 歳以上が対象です**
- **開催日の前に、Claude Desktop で Code タブを開き、Local が選べることを確かめてください。** 会社や学校が管理しているパソコンでは、管理者の設定で Local が使えないことがあります。Local の説明: 自分のパソコンの上で、自分のファイルを使って動かす選び方です。使えない場合は、事前に管理者へ確認してください
- Node.js やターミナルの準備は要りません。ほかのソフトを入れる手順はありません
- **練習用フォルダは、資料のページからダウンロードします**（当日の最初でも間に合います）

**見学だけの参加**（実習はせず、画面を見て流れを知る）: ［要確認: 受け付けるかどうか。受け付ける場合は、有料プランなしでよいことと、動画・資料の見方を書く］

### 当日の進め方

各 Step は **「解説動画 → ハンズオン」** の順です。最初に動画（約 3〜4 分）で、やることと確かめるところをつかみます。そのあと、同じ Step の手順で実際に手を動かします。動画は全部で 8 本、合計約 31 分です。動画の流し方（画面共有か、各自の画面で再生か）は［要確認］。

| Step | やること | 動画 | ハンズオン |
|---|---|---|---|
| はじめに | Chat・Cowork・Claude Code の違い | ― | 約 10 分 |
| 0 | アプリと練習用フォルダを用意する | 約 3 分 | 約 9 分 |
| 1 | Code タブでフォルダを開き、中身を説明してもらう | 約 4 分 | 約 10 分 |
| 2 | 作りたいものを伝えて、先に計画を出してもらう | 約 4 分 | 約 10 分 |
| 3 | 変更を承認してページを作り、開いて合計を確かめる | 約 4 分 | 約 15 分 |
| 4 | 見た目や並び順を、言葉で頼んで直す | 約 4 分 | 約 10 分 |
| 5 | 10 月の売上データを入れて、合計が合うかを確かめる | 約 4 分 | 約 10 分 |
| 6 | 道具の中身を確かめ、使うときの約束を見る | 約 4 分 | 約 5 分 |
| 7・まとめ | 自分の作業から 1 つ選んで、頼み方を書く。便利な機能の紹介（Step 8）と、見返し用のチェックリストの案内を含む | 約 4 分 | 約 10 分 |

最後の Step 7 では、1〜2 名の方に、選んだ作業と「確かめ方」を発表していただく時間があります。話したくない方は、チャットに書く形にもできます。［要確認: 発表は希望者のみ・チャット可、でよいか］

### 身につくこと

- Code タブでフォルダを開き、**言葉で頼んで Web ページを 1 つ作れる**
- **計画を先に見て、変更を 1 つずつ承認する**進め方
- できた道具を、**答えが分かっているデータと、別のデータ**で確かめる方法
- 自分の作業の中から、道具にすると楽になるものを選び、**頼み方を書く**こと

### 事前にお伝えしておくこと

- **Claude Code は、自分のパソコンの上で、ファイルを作ったり書き換えたりします。** 作業フォルダに選ぶのは練習用フォルダだけにして、Claude が出す変更は、1 つずつ内容を見てから承認します。承認のしかたは、ハンズオンの中で練習します
- **使うデータは、すべて練習用の架空のものです。** お店の本物の売上データや、個人情報の入ったファイルは、作業するフォルダに入れないでください
- Claude が読んだファイルの中身は、答えを作るために Anthropic の AI へ送られます。Local を選んでも同じです
- AI は計算や読み取りを間違えることがあります。このハンズオンでは、**合計の数字を自分で確かめる**ところまでをやります
- 同じお願いでも、できるページの色・配置・グラフの形は、人によって変わります。そろえるのは見た目ではなく、**合計の数字**です
- Claude の使用量には上限があります。ハンズオン中に上限に達したときは、運営にチャットで知らせてください。そのあとは、用意してある**完成見本のページ**を開いて、Step 5 の確かめ方を体験する形に切り替えます
- カメラオフでも参加できます。進み具合を知るために、絵文字リアクションなどでの合図をお願いすることがあります。分からないところは、チャットで質問してください
