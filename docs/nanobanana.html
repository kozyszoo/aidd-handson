🍌 そもそも Nano Banana とは？

Nano Banana（ナノバナナ）は、本ハンズオンで作成する架空のキャラクター名およびブランドのテーマでもあり、同時に Google の最新画像生成・編集モデルの愛称でもあります。この教材では Nano Banana 2（Gemini 3.1 Flash Image）を使います。テキストで画像を作るだけでなく、「会話しながら画像を直していける」のが最大の特徴です。

✨ 特徴 1

会話で編集できる

「背景を夜に」「ロゴを左上へ」のように、言葉で何度でも修正を重ねられます。

✨ 特徴 2

同じ人物・物を保てる

同じキャラクターや商品を、ポーズや背景を変えても崩さず描き続けられます（一貫性）。

✨ 特徴 3

複数画像を合成できる

「この人物 ＋ この背景 ＋ このロゴ」を 1 枚に自然に組み合わせられます。

✨ 特徴 4

文字をきれいに描ける

従来 AI が苦手だった、画像内の正確な文字入れが得意になりました。

🎯 このハンズオンで作るもの

このハンズオンでは、Nano Banana を使って自分（または架空の店・サービス）のブランドキットを作ります。1 つのモチーフを軸に、用途の違う画像を一式そろえるのがゴールです。

🎁 完成イメージ（成果物）
  1. マスコット／ロゴ（Step 1・3 で生成し、ポーズ違いを量産）
  2. 商品・サービスのモックアップ（Step 2・4 で編集・合成）
  3. SNS 用バナー（Step 5 で文字入れ）
  4. アイコン・OGP 画像など一式（Step 6 でまとめて仕上げ）

✅ 必要な環境

  • Google アカウント … Gemini の画像編集の利用は18歳以上が対象です。学校用アカウントは利用条件が異なるため、事前に確認してください。
  • Google AI Studio／Gemini API の利用は18歳以上が対象です。
  • Gemini アプリ（ブラウザ） … https://gemini.google.com/ にアクセスできれば OK。スマホアプリでも可。
  • 素材写真を 1〜2 枚（任意） … 自分の似顔絵のもとにしたい写真、商品の写真、好きなロゴなど。なくても進められます。
ℹ️ APIで新しく画像生成を始める場合は、Nano Banana 2.1 を使います。今回はコードを書かずに使える Gemini アプリ（Web）を使います。API での使い方は最後の「さらに深掘り」で触れます。
⚠️ 生成画像には Google の電子透かし（SynthID）が埋め込まれます。また、実在の人物・他者の著作物・ブランドロゴをそのまま使うと権利上の問題になり得ます。ハンズオンでは自分の写真か架空のモチーフを使いましょう。

💰 無料版でどれくらい作れる？（プランごとの目安）

無料でも始められますが、年齢や利用上限によって途中の操作ができない場合があります。たくさん作り直していると、途中で「上限に達しました」と出ることがあります。

Step 1: Gemini で1枚生成してみる

まずは「テキストから画像を作る」感覚をつかみましょう。難しく考えず、思いついた言葉をそのまま打ち込むのがコツです。

1-1. Gemini を開く

https://gemini.google.com/ にアクセスし、Google アカウントでログインします。中央に入力欄が表示されるので、左側の ＋（「アップロードとツール」） ボタンを開き、メニュー内の 「画像を作成」 が選べることを確認しましょう。

ℹ️ Gemini はバージョンによって画面が少し変わります。「画像を作って」と日本語で頼むだけでも、自動的に画像生成モデル（Nano Banana）が呼び出されます。無料の個人アカウントでは「Flash-Lite」（Nano Banana 2 Lite）が使われます。複数の画像の参照や複数回の編集を行うには、「Flash」または「Pro」が利用できる有料プラン（Google AI Plus、Google AI Pro など）のアカウントが必要です。

↑ Gemini を開いた直後の画面。中央の入力欄に文章を打ち、左の ＋ ボタン（「アップロードとツール」）から画像のアップロードや「画像を作成」が選べます

1-2. 最初のプロンプトを打つ

今回の「ブランドの主役（マスコット）」を 1 体作ります。下記をそのまま貼り付けて送信してみましょう。あとで全ステップで使い回す主役なので、気に入る 1 枚ができるまで何度か作り直して構いません。

📝 プロンプト例（コピペして送信） 
かわいいバナナのキャラクターを作ってください。
- 二足歩行で、笑顔で手を振っている
- フラットでシンプルなマスコットデザイン（太めの輪郭線）
- 背景は無地のパステルイエロー
- 正方形（1:1）、ロゴにも使える清潔感のあるテイスト

↑ 入力欄にプロンプトを貼り付けた状態（送信前）。このあと右下の ↑ 送信ボタンを押します

↑ 上のプロンプトで生成したマスコットの例（この子を「主役」として全ステップで使い回します）

💡 プロンプトのコツは「①何を ②どんな見た目で ③背景・構図 ④用途」の順で書くこと。箇条書きでも自然文でも伝わります。英語に直す必要はありません。

1-3. 言葉で修正してみる

生成された画像が少しイメージと違っても大丈夫。そのまま会話を続けて直していきます。これが Gemini アプリ内蔵の Nano Banana による編集機能の本領です。

📝 修正プロンプト例 
いい感じです！もう少しだけ目を大きく、色を鮮やかな黄色にしてください。
背景は今のままで OK です。

1-4. 画像を保存する

気に入った画像が出たら、画像にマウスを乗せると右上に表示される 3 つのアイコン（共有・コピー・ダウンロード（↓））から「ダウンロード」を押して手元に保存します（または画像を右クリック →「画像を保存」でも OK）。このマスコットを「main-mascot.png」などの名前で保存しておきましょう。以降のステップで使います。

↑ 生成結果の画面。画像の 右上に並ぶアイコンのうち ダウンロード（↓）で手元に保存できます（共有・コピーも可能）

⚠️ 思い通りにならないときは、いきなり全部を変えず「1 回につき 1 つだけ」修正を頼むと、狙った所だけ変わりやすくなります。

Step 2: 部分編集（描き込み・差し替え）

次は「すでにある画像の一部だけを直す」編集です。アップロードした写真にも、Step 1 で作ったマスコットにも使えます。

2-1. 画像をアップロードする

入力欄の ＋（画像を追加）アイコンから、編集したい画像をアップロードします。手元の素材写真がなければ、Step 1 で保存したマスコットを使ってください。

↑ 入力欄左の ＋ ボタンを押すとこのメニューが開きます。「ファイルをアップロード」から編集したい画像を選びます（初めてだと迷いやすいポイントです）

2-2. 「ここだけ変えて」と頼む（テキスト指示）

画像全体を作り直すのではなく、チャットで場所と変更内容を具体的に指定して、その部分だけを編集します。

📝 プロンプト例（背景の差し替え） 
アップロードした画像のキャラクターはそのまま残し、
背景だけを「明るいカフェの店内」に変えてください。
キャラクターの形・色・表情は変更しないでください。
📝 プロンプト例（物の追加・削除） 
このキャラクターの手に、湯気の立つコーヒーカップを持たせてください。
他の部分はそのままにしてください。
ℹ️ 「他は変えないで」「形・色はそのまま」と添えるのが、テキストによる部分編集を成功させる最大のコツです。これがないと全体が描き直されてしまうことがあります。

2-3. スケッチツールで編集箇所を指定する（最新機能）

現在の Gemini アプリ（Web版）では、アップロードした画像または生成された画像をクリックすると拡大表示モードに入ります。このとき画像の下にカラーパレットと「スケッチ」「テキスト」ツールが並びます。「スケッチ」を使うと、より直感的に部分修正が行えます。

  1. 編集したい画像をクリックして拡大表示します。
  2. 画像の下に並ぶ 「スケッチ」（鉛筆型のアイコン） をクリックします（必要なら色も選択）。
  3. 変更したい場所（背景や手元など）を丸や描き込みで示します。
  4. 入力欄に「ここを明るいカフェの店内に変更して」「コーヒーカップを持たせて」などのプロンプトを入力して送信します。
💡 スケッチツールのコツ: 描き込みで場所を示し、変更内容は文章でも伝えます。「テキスト」ツールを使うと、画像内の特定の位置に文字を書き込む指示も出せます。

2-4. 不要なものを消す

写真から邪魔な要素を消すこともできます（いわゆる「消しゴムマジック」的な編集）。

📝 プロンプト例（消す） 
背景に写っている通行人を自然に消して、
その部分を周囲の風景になじむように補完してください。
💡 商品写真があれば、ここで背景を白に飛ばす・余計な映り込みを消すとそのまま EC 用の商品画像になります。これも立派なブランドキットの 1 枚です。

Step 3: キャラクターを固定する（一貫性）

Nano Banana の真骨頂が「同じキャラクターを、別のシーンでも崩さず描く」こと（キャラクターの一貫性保持）。Step 1 のマスコットを主役に、ポーズ違い・シーン違いを量産します。

3-1. 主役の画像を添えて指示する

Step 1 のマスコット画像をアップロードした状態で、「この子のまま」と前置きして別シーンを頼みます。

📝 プロンプト例 
アップロードしたこのバナナのキャラクターを主役にして、
同じ顔・同じ配色・同じ画風のまま、次のシーンを描いてください。

シーン: ノートパソコンの前に座って、楽しそうにタイピングしている
背景: 観葉植物のある明るい部屋
構図: 横長（16:9）

3-2. ポーズ違いを一気に並べる

1 回のプロンプトで複数バリエーションを頼むこともできます。LINE スタンプ風の展開です。

📝 プロンプト例（バリエーション） 
同じキャラクター・同じ画風のまま、表情とポーズ違いを4種類、
1枚の画像に2×2のグリッドで並べてください。
「喜ぶ / 考える / 困る / 親指を立てる」の4パターンでお願いします。

↑ 同じ主役のまま、表情・ポーズ違いを一度に生成した例（LINE スタンプ風の展開）

ℹ️ うまく似なかったら、もとの画像をもう一度アップロードし直し、「顔の形と色は厳密にこの画像に合わせて」と強めに指定すると一貫性が上がります。
💡 これは商品でも同じです。自分の商品写真を主役にすれば、「同じ商品を別の背景・別アングルで撮ったような画像」を何枚も作れます。撮影し直さずにカタログが増やせます。

Step 4: 複数画像を合成する

「人物（またはマスコット）＋ 背景 ＋ 小物」など、複数の画像を 1 枚に組み合わせる編集です。コラージュではなく、自然になじませてくれます。

4-1. 2枚以上の画像をまとめてアップロード

＋アイコンから複数の画像を同時にアップロードします。たとえば「① マスコット」「② 商品写真」の 2 枚。

4-2. どれをどう組み合わせるか伝える

どの画像が何なのかを言葉でひも付けしてあげると、狙い通りに合成されます。

📝 プロンプト例（商品モックアップ） 
1枚目はマスコットキャラクター、2枚目は商品（マグカップ）です。
このマグカップに、マスコットのイラストをプリントしたデザインにして、
木目のテーブルの上に置いた商品写真風の1枚を作ってください。
照明は自然光、構図は正方形でお願いします。

↑ 「マスコット」＋「マグカップ」の2枚を合成して作った商品モックアップの例

📝 プロンプト例（着せ替え・持ち物の合成） 
1枚目の人物が、2枚目のTシャツデザインのTシャツを着ている様子を
自然に合成してください。顔と体型は1枚目のままにしてください。
ℹ️ 「1枚目は〜、2枚目は〜」と各画像の役割を最初に説明するのがコツです。枚数が増えるほど、この説明が効いてきます。

Step 5: 文字を入れてバナーにする

従来の画像 AI は文字が苦手でしたが、Nano Banana は正確な文字入れが得意です。SNS バナーやサムネイルを作りましょう。

5-1. 文字を「カギカッコで正確に」指定する

入れたい文字はそのままの表記をカギカッコ等で明示します。フォントの雰囲気や配置も言葉で指定できます。

📝 プロンプト例（SNS バナー） 
横長（16:9）のSNS用バナーを作ってください。
- 主役: アップロードしたバナナのマスコット（右側に配置）
- 左側に大きく見出しテキスト「バナナ商店、開店！」
- その下に小さめのサブテキスト「毎週日曜オープン」
- 配色はイエロー基調でポップに、文字ははっきり読める太めの書体

↑ 文字入れの例。日本語の「バナナ商店、開店！」「毎週日曜オープン」も崩れず描けます

5-2. 文字だけ直す

文字の打ち間違いや変更も、会話で直せます。

📝 プロンプト例（文字修正） 
デザインはそのままで、サブテキストだけ
「毎週日曜オープン」から「毎週土日オープン」に変えてください。
⚠️ 長い文章や、漢字・記号が多い文字はまれに崩れることがあります。崩れたら「この部分の文字を『〇〇』に直して」と再指定するか、文字数を減らすと安定します。
💡 縦長（9:16）を指定すればストーリーズ／ショート動画のサムネ、横長（16:9）ならYouTube サムネや OGPに。サイズ違いで何枚か作っておくと便利です。

Step 6: ブランドキットを仕上げる

ここまでで作った主役・シーン・バナーを使って、用途別の画像一式に整えます。これで「自分のブランドキット」の完成です。

6-1. アイコン（正方形）を作る

📝 プロンプト例 
このマスコットの顔をアップにした、SNSアイコン用の正方形画像を作ってください。
背景は無地のイエロー、シンプルで小さく表示しても分かりやすいデザインで。

6-2. ヘッダー／OGP（横長）を作る

📝 プロンプト例 
同じマスコットと配色で、横長（16:9）のヘッダー画像を作ってください。
中央にサービス名「Banana Shop」のロゴ風テキストを入れて、
余白を広めにとった、清潔感のあるデザインでお願いします。

📺 さらに深掘り

Nano Banana（Gemini 画像モデル）をさらに使いこなすための参考情報とリンク集です。慣れてきたら、コードからの自動化にも挑戦してみてください。

🧑‍💻 コードから使う（Gemini API / AI Studio）

画像生成モデルは Google AI Studio で API キーを取得すれば、Python や Node.js から呼び出せます。大量生成や、他システムへの組み込みに向いています。Nano Banana 2.1 を API で呼び出す際のモデル名は gemini-nano-banana-2.1です。公式ドキュメントで最新のモデル名を必ず確認してください。旧モデル Gemini 2.5 Flash Image は非推奨です。この教材では、現在推奨されている画像生成モデルを使います。Imagen 4 は2026年8月17日に Gemini API での提供を終了しました。Pythonで実行する前に、課金設定と料金を確認してください。

🐍 Python での画像生成例 
from google import genai
import base64

# クライアントの初期化（APIキーは環境変数 GEMINI_API_KEY または引数から読み込みます）
client = genai.Client(api_key="YOUR_API_KEY")

# Nano Banana 2.1（gemini-nano-banana-2.1）による画像生成
interaction = client.interactions.create(
    model="gemini-nano-banana-2.1",
    input="A cute banana character sitting in front of a laptop, digital art",
)

# 生成された画像の保存（画像データを base64 から戻して書き込む）
with open("generated_banana_0.png", "wb") as f:
    f.write(base64.b64decode(interaction.output_image.data))
print("画像を保存しました: generated_banana_0.png")
