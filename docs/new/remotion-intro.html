🎬 Remotion 入門ハンズオン

React のコードで動画(MP4)を作る

Remotion は、タイムラインを GUI で編集する代わりに、React のコンポーネントとして「各フレームの見た目」をプログラムで定義して動画を作るツールです。ソースコードは公開されていますが、利用には独自のRemotion Licenseが適用されます。このハンズオンでは、ゼロから短い動画を 1 本作り、MP4 として書き出すまでを実際に手を動かして体験します。

所要時間の目安: 約 60〜80 分 ／ レベル: 入門（Node.js と React の基礎が少しあると安心）

🙋 みなさんの進捗状況を知りたいので、うまく進んでいる場合も、進んでいない場合も絵文字リアクションを積極的に返してください！進んでないよ、というときも遠慮なく！

はじめに

Remotion とは何か

Remotion は、ふだん Web 制作で使う React（JavaScript / TypeScript）のコードで動画を作るためのフレームワークです。動画編集ソフトのようにタイムライン上でクリップを並べるのではなく、「このフレームのときに画面はこう見える」を関数として書くと、Remotion がそれを 1 枚ずつ画像にして連結し、MP4 にしてくれます。

🎯 ゴール（完成イメージ）

「テキストがフェードインし、図形がバネのように飛び出してくる、数秒の動画」を Remotion で作り、npx remotion render で MP4 ファイルとして書き出せるようになります。コードでアニメーションを表現する感覚をつかむのが目標です。

🤔 何が嬉しいの？（動画編集ソフトとの違い）

観点 一般的な動画編集ソフト Remotion（コードで作る）
作り方 マウスでクリップを並べる React コンポーネントを書く
再現性 / 修正 手作業のやり直しが多い コードを直せば全フレームに即反映
量産 1 本ずつ手作業 データを差し替えるだけで自動量産（例: 100 人分の表彰動画）
Web 技術の活用 専用ソフト内で完結 HTML / CSS / npm パッケージがそのまま使える
💡 一言でいうと: 「Web ページを作る要領で動画が作れる」ツールです。すでに React や CSS を触ったことがある人なら、新しい概念は「フレーム」と「fps」だけ覚えれば動画が作れます。

✅ 必要な環境（前提知識）

  • Node.js（推奨は現行の LTS 版、v20 以上）— Remotion は Node.js 上で動きます
  • JavaScript / React の基礎— コンポーネント・JSX・props がなんとなく分かれば十分です（深い知識は不要）
  • ターミナル（コマンドライン）が少し使えること（cd や npm を打てればOK）
  • エディタ（VS Code など）
💡 React を触ったことがなくても大丈夫です。このハンズオンのコードはすべてコピペできる完成形で示し、どこが何をしているかを 1 つずつ日本語で説明します。

全体像 — コードで動画を作るとは

Remotion を触る前に、たった 2 つの考え方だけ押さえておきましょう。これが分かれば、後のコードはすべて理解できます。

① 動画は「パラパラ漫画」＝フレームの集まり

どんな動画も、実は静止画（フレーム）を高速でめくっているだけです。Remotion でも考え方は同じで、「今が何フレーム目か」に応じて画面の見た目を変えると、それがアニメーションになります。

② fps（1秒あたりのフレーム数）と durationInFrames（総フレーム数）

  • fps: 1 秒間に何枚の絵を見せるか。30 なら 1 秒 = 30 フレーム。
  • durationInFrames: 動画全体が何フレームあるか。これが動画の長さを決めます。
🧮 長さの計算式

動画の秒数 = durationInFrames ÷ fps
例) fps = 30、durationInFrames = 90 → 90 ÷ 30 = 3 秒の動画

💡 Remotion では useCurrentFrame() というフックで「今のフレーム番号」を取得し、その数字をもとに位置・透明度・大きさを計算します。「フレーム番号 → 見た目」の関数を書くのが Remotion の本質です。

Step 1: 環境構築

まずは Remotion を動かす準備をします。やることは「Node.js の確認 → プロジェクト作成 → Studio 起動」の 3 つだけです。

1-1. Node.js が入っているか確認する

MacではmacOS 15（Sequoia）以降が必要です。LinuxではLibc 2.35以上と、公式ページに記載された追加パッケージが必要です。

ターミナルを開いて、次のコマンドでバージョンを確認します。v20 以上が表示されれば OK です。

# Node.js のバージョンを確認（v20 以上。できれば LTS 版）
node -v

# npm（パッケージ管理ツール）のバージョンも確認
npm -v
⚠️ コマンドが見つからない / 古い場合: Node.js が未インストール、または古い可能性があります。Node.js 公式サイトから LTS 版をインストールしてください。インストール後はターミナルを開き直すと反映されます。

1-2. Remotion プロジェクトを作成する

Remotion 公式の作成コマンドを実行します。テンプレートを選ぶ画面が出たら、まずは 「Hello World」テンプレート（TypeScript）を選びましょう。

# 対話形式で Remotion プロジェクトを作成する
npm create video@latest

途中で「プロジェクト名」を聞かれるので、たとえば my-first-video と入力します。完了すると、その名前のフォルダが作られます。

💡 このコマンドが何をしているか: create video は Remotion 公式の「ひな型生成ツール」です。必要なファイル一式（設定・サンプルのコンポジション・package.json）を自動で用意し、依存パッケージのインストールまで行ってくれます。手作業の初期設定が不要になります。

1-3. Studio（プレビュー）を起動する

作られたフォルダに移動し、開発サーバー（Remotion Studio）を起動します。

# 作成したプロジェクトフォルダに移動
cd my-first-video

# Remotion Studio（プレビュー）を起動
npm run dev

ブラウザが自動で開き、Remotion Studio が表示されます。左にコンポジション一覧、中央にプレビュー、下に再生バー（タイムライン）があります。再生ボタンを押すと、サンプル動画がフレーム単位で再生されます。

（Remotion Studio の初期画面 — 左にコンポジション一覧、中央にプレビュー、下に再生バー）
💡 Studio はコードを保存すると自動で再描画されます。以降のステップでは、この Studio を開いたままコードを書き換えて、結果をすぐ確認していきます。

Step 2: 最初のコンポジション

ここからコードを書きます。Remotion で動画を作るには、「コンポジション（Composition）」を定義する必要があります。コンポジションとは 動画 1 本の設定（サイズ・長さ・fps）と、中身のコンポーネントの組み合わせ のことです。

2-1. registerRoot と Composition の関係

Remotion のプロジェクトには、必ず「ルート（Root）」を登録するファイルがあります。ひな型では src/index.ts がエントリーポイントで、そこから registerRoot() でルートコンポーネントを登録しています。

// src/index.ts — Remotion に「ここが入口だよ」と教えるファイル
import { registerRoot } from 'remotion';
import { RemotionRoot } from './Root';

// ルートコンポーネントを登録する（これが動画一覧の大元になる）
registerRoot(RemotionRoot);

そのルートの中で、<Composition> を並べて「どんな動画があるか」を宣言します。次が今回作る最小のルートです。

// src/Root.tsx — どんな動画(コンポジション)があるかを宣言する場所
import { Composition } from 'remotion';
import { MyVideo } from './MyVideo';

export const RemotionRoot = () => {
  return (
    <>
      {/* 1つの動画 = 1つの Composition */}
      <Composition
        id="MyVideo"            // Studio 上での表示名・render 時の指定名
        component={MyVideo}     // 実際に描画するコンポーネント
        durationInFrames={90}   // 総フレーム数（90 ÷ 30fps = 3秒）
        fps={30}                // 1秒あたり 30 フレーム
        width={1280}            // 動画の横幅(px)
        height={720}            // 動画の高さ(px)
      />
    </>
  );
};
💡 Composition の属性が動画の「枠」を決める: width / height が解像度、fps がなめらかさ、durationInFrames が長さです。ここを変えるだけで、縦長(ショート動画)や長尺にも対応できます。

2-2. テキストを表示するコンポーネントを作る

次に、component に指定した中身（MyVideo）を作ります。画面いっぱいに要素を置くには <AbsoluteFill> を使うと便利です。これは「画面全体を覆う div」だと思ってください。

// src/MyVideo.tsx — 実際の見た目を定義するコンポーネント
import { AbsoluteFill } from 'remotion';

export const MyVideo = () => {
  return (
    // AbsoluteFill = 画面全体を覆うコンテナ（中央寄せ等もCSSで指定）
    <AbsoluteFill
      style={{
        backgroundColor: '#15203a',   // 背景色
        justifyContent: 'center',     // 縦中央
        alignItems: 'center',         // 横中央
      }}
    >
      <h1 style={{ color: 'white', fontSize: 80 }}>
        Hello Remotion!
      </h1>
    </AbsoluteFill>
  );
};

保存すると Studio のプレビューが更新され、紺色の背景に「Hello Remotion!」が中央表示されます。まだ動きはありませんが、これが動画の 1 フレーム（＝全フレーム同じ絵）です。次のステップで動かします。

📷 スクリーンショット差し込み位置
（中央に "Hello Remotion!" が表示された Studio プレビュー）
💡 ここまでは普通の React と同じです。JSX で書いた見た目が、そのまま動画のフレームになる——この感覚がつかめれば、もう Remotion の半分は理解できています。

Step 3: アニメーションをつける

いよいよ動きをつけます。Remotion のアニメーションは、「今のフレーム番号」を取得し、その数字から見た目の値（透明度・位置・大きさ）を計算するだけです。難しい再生制御はありません。

3-1. useCurrentFrame() で「今のフレーム」を知る

まずは現在のフレーム番号を表示してみましょう。useCurrentFrame() は再生位置が進むたびに増える数字を返します。

import { AbsoluteFill, useCurrentFrame } from 'remotion';

export const MyVideo = () => {
  // 今が何フレーム目か（0, 1, 2, ... と進む）
  const frame = useCurrentFrame();

  return (
    <AbsoluteFill style={{ backgroundColor: '#15203a', justifyContent: 'center', alignItems: 'center' }}>
      <h1 style={{ color: 'white', fontSize: 80 }}>frame: {frame}</h1>
    </AbsoluteFill>
  );
};

再生すると数字が 0 から増えていきます。これが「動画は時間とともに frame が進む」という Remotion の心臓部です。

3-2. interpolate() でフェードインする

interpolate() は「ある範囲の入力を、別の範囲の出力に変換する」関数です。たとえば「フレーム 0〜30 を、透明度 0〜1 に対応させる」と書けば、最初の 1 秒でじわっと現れるフェードインになります。

import { AbsoluteFill, useCurrentFrame, interpolate } from 'remotion';

export const MyVideo = () => {
  const frame = useCurrentFrame();

  // frame が 0→30 に進む間に、opacity を 0→1 へ変化させる
  const opacity = interpolate(
    frame,        // 入力：今のフレーム
    [0, 30],      // 入力の範囲（0〜30フレーム）
    [0, 1],       // 出力の範囲（透明→不透明）
    {
      // 範囲外でも値が飛び出さないように両端で止める
      extrapolateLeft: 'clamp',
      extrapolateRight: 'clamp',
    }
  );

  return (
    <AbsoluteFill style={{ backgroundColor: '#15203a', justifyContent: 'center', alignItems: 'center' }}>
      {/* 計算した opacity をスタイルに渡すだけ */}
      <h1 style={{ color: 'white', fontSize: 80, opacity }}>Hello Remotion!</h1>
    </AbsoluteFill>
  );
};
⚠️ extrapolateLeft / Right: 'clamp' を忘れずに。これが無いと、入力範囲(0〜30)の外側でも値が計算され続け、opacity が 1 を超えたりマイナスになったりします。「両端で止める」= clamp と覚えておくと安全です。

3-3. spring() でバネのような動きを出す

直線的な動きだと機械的に見えます。spring() を使うと、バネのようにふわっと弾む自然な動きになります。ここでは図形を下から飛び出させてみましょう。

import { AbsoluteFill, useCurrentFrame, useVideoConfig, spring, interpolate } from 'remotion';

export const MyVideo = () => {
  const frame = useCurrentFrame();
  // fps は spring の動きの速さ計算に必要なので取得する
  const { fps } = useVideoConfig();

  // 0 → 1 へ「バネのように」変化する値（弾む動き）
  const progress = spring({
    frame,    // 今のフレーム
    fps,      // コンポジションの fps
    config: { damping: 12 },  // damping を小さくするほどよく弾む
  });

  // progress(0→1) を、Y方向の移動量(300px下→0)に変換
  const translateY = interpolate(progress, [0, 1], [300, 0]);

  return (
    <AbsoluteFill style={{ backgroundColor: '#15203a', justifyContent: 'center', alignItems: 'center' }}>
      <div
        style={{
          width: 200,
          height: 200,
          borderRadius: 24,
          backgroundColor: '#2563eb',
          // 計算した値で位置と大きさを動かす
          transform: `translateY(${translateY}px) scale(${progress})`,
        }}
      />
    </AbsoluteFill>
  );
};

再生すると、青い四角が下からバネのように跳ねて中央に収まります。spring() が返す 0→1 の値を interpolate() で「移動量」や「拡大率」に変換するのが、Remotion アニメーションの定番パターンです。

📷 スクリーンショット差し込み位置
（青い四角がバネのように飛び出すアニメーションの途中フレーム）
💡 3 つのフックの役割まとめ:
・useCurrentFrame() … 今のフレーム番号を取得
・interpolate() … 数値を別の範囲へ変換（位置・透明度・大きさ）
・spring() … 自然な弾みのある 0→1 の値を生成
この 3 つの組み合わせだけで、ほとんどの基本アニメーションが作れます。

Step 4: 仕上げ（背景・複数要素・Sequence）

動きが分かったら、要素を組み合わせて「ちゃんとした 1 本」に仕上げます。ポイントは 背景の作り込み と、<Sequence> による 時間差での表示 です。

4-1. Sequence で「いつ表示するか」をずらす

<Sequence> は、中の要素を「指定したフレームから登場させる」ためのコンポーネントです。from で開始フレーム、durationInFrames で表示する長さを指定します。これでテキストと図形を時間差で出す演出ができます。

先に src/Title.tsx と src/Box.tsx を作ります。Titleには3-2、Boxには3-3の修正済みコードをコピーし、export const MyVideo をそれぞれ export const Title、export const Box に変えます。両方の AbsoluteFill の backgroundColor を削除し、背景色は親のMyVideoに指定します。

import { AbsoluteFill, Sequence } from 'remotion';
import { Title } from './Title';   // Step3 で作ったような部品を分割
import { Box } from './Box';

export const MyVideo = () => {
  return (
    <AbsoluteFill style={{ backgroundColor: '#15203a' }}>
      {/* 0フレーム目から、まず図形を登場させる */}
      <Sequence from={0} durationInFrames={90}>
        <Box />
      </Sequence>

      {/* 30フレーム目（1秒後）から、遅れてテキストを登場させる */}
      <Sequence from={30} durationInFrames={60}>
        <Title />
      </Sequence>
    </AbsoluteFill>
  );
};
💡 Sequence の中では frame が 0 にリセットされるのが重要ポイントです。from={30} の Sequence の中で useCurrentFrame() を呼ぶと、動画全体の 30 フレーム目でもその部品にとっては 0 フレーム目として扱われます。だから各部品は「自分が出てくる瞬間を 0」としてアニメーションを書けます。

4-2. 背景に動きをつける（おまけ）

背景を一色ベタ塗りではなく、ゆっくり変化するグラデーションにすると、ぐっと「動画らしさ」が出ます。これも frame をもとに色を計算するだけです。

import { AbsoluteFill, useCurrentFrame, interpolate } from 'remotion';

export const Background = () => {
  const frame = useCurrentFrame();
  // フレームに応じてグラデーションの角度をゆっくり回す
  const angle = interpolate(frame, [0, 90], [0, 60]);

  return (
    <AbsoluteFill
      style={{
        background: `linear-gradient(${angle}deg, #15203a, #2563eb)`,
      }}
    />
  );
};

この Background を MyVideo の一番下（最初の子要素）に置けば、その上にテキストや図形が重なって表示されます。要素を重ねる順番＝記述する順番です（後に書いたものが手前）。

💡 部品を分けるコツ: 背景・タイトル・図形を別々のコンポーネント（Background / Title / Box）に分けると、それぞれが「自分のアニメーション」に集中でき、コードが読みやすくなります。Sequence で並べるだけで構成を組み替えられます。

Step 5: レンダリング（MP4 に書き出す）

プレビューで満足できたら、最後にMP4 ファイルとして書き出します。Studio はあくまでプレビューなので、配布できる動画ファイルにするにはレンダリングが必要です。

5-1. render コマンドで書き出す

プロジェクトのフォルダで、次のコマンドを実行します。MyVideo の部分は、Step 2 で <Composition> に付けた id を指定します。

# 形式: npx remotion render <コンポジションid> <出力ファイル名>
npx remotion render MyVideo out/video.mp4

初回は動画化に必要なブラウザ（Chrome Headless Shell）のダウンロードが入ることがあります。完了すると、進捗バーが表示され、最後に出力先のパスが表示されます。

💡 裏側で何が起きているか: Remotion はヘッドレスブラウザで各フレームを 1 枚ずつスクリーンショットのように描画し、それを FFmpeg で連結して MP4 にエンコードしています。つまり「Studio で見えていた絵」がそのまま動画ファイルになります。

5-2. 出力先を確認する

上のコマンドなら、プロジェクト内の out/video.mp4 に動画が保存されます。ファイルを開いて、Studio のプレビューと同じ動きになっているか確認しましょう。

# 出力されたフォルダの中身を確認（mac / Linux）
ls -lh out/

# 動画を開く（mac の場合）
open out/video.mp4
📷 スクリーンショット差し込み位置
（render 実行中の進捗バーと、書き出された out/video.mp4）
💡 よく使うオプション: --codec=h264（既定。一般的な MP4）、--props=./props-taro.json（後述のデータ駆動でコンポーネントに値を渡す）、--frames=0-30（一部だけ書き出してチェック）など。まずは引数なしのシンプルな形で 1 本出せれば十分です。

（任意）応用 — もっと Remotion を活かす

基本ができたら、次のような発展も Remotion の得意分野です。興味があるものを 1 つ試してみてください。

① 音声・BGM をつける

<Html5Audio> コンポーネントで音声ファイルを重ねられます。public/ フォルダに音源を置き、staticFile() で参照します。音声の最新の公式推奨は @remotion/media の <Audio> です。このハンズオンでは追加パッケージを入れないため、remotion に含まれる <Html5Audio> を使います。

import { AbsoluteFill, Html5Audio, staticFile } from 'remotion';

export const MyVideo = () => {
  return (
    <AbsoluteFill>
      {/* public/bgm.mp3 を動画に重ねる */}
      <Html5Audio src={staticFile('bgm.mp3')} />
      {/* ...映像の中身... */}
    </AbsoluteFill>
  );
};

② データ駆動で動画を量産する

コンポーネントに props を受け取らせ、レンダリング時に --props で値を差し替えれば、同じテンプレートで中身違いの動画を何本も自動生成できます（例: 受賞者名だけ変えた表彰動画を人数分）。

// 名前を受け取って表示するコンポーネント
type Props = { name: string };

export const Award: React.FC<Props> = ({ name }) => {
  return <h1>祝・{name} さん 受賞！</h1>;
};

上のコードを src/Award.tsx に保存します。src/Root.tsx に import { Award } from './Award'; を追加し、既存のCompositionの隣に <Composition id="Award" component={Award} durationInFrames={90} fps={30} width={1280} height={720} defaultProps={{ name: '受賞者' }} /> を追加します。

プロジェクト直下に props-taro.json（内容は {"name":"山田太郎"}）と props-hanako.json（内容は {"name":"佐藤花子"}）を作ります。

# レンダリング時に props を渡して中身を差し替える
npx remotion render Award out/taro.mp4 --props=./props-taro.json
npx remotion render Award out/hanako.mp4 --props=./props-hanako.json
💡 さらに進めると、CSV やスプレッドシートの行を読み込んでループで renderMedia()（Node.js API）を呼び、数百本を完全自動で書き出すこともできます。「コードで動画を作る」最大の強みがここです。
